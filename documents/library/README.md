Reusable documents shared across all visa/travel applications. Files live in `_files/`.

**Refresh rule:** before each application, check the "Valid until" column. Anything expired or stale must be re-requested.

## Validity windows cheat-sheet

| Item | Max age accepted |
|---|---|
| Bank statements | 3 months |
| Bank certificate / COE | ~1 month (as recent as possible) |
| Medical exam / chest X-ray | 3 months (only for 6+ month stays) |
| Police certificate | 6 months (only for 24+ month total stays) |
| Passport | must have ≥6 months validity beyond departure |
