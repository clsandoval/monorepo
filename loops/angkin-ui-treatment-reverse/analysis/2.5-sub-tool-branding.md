# 2.5 — Sub-Tool Branding

## The Core Decision: One Brand, Not 148 Brands

**Angkin is the brand. Tools are features.**

With 148 compliance tools across 14 regulatory domains, the branding system must scale without fragmenting. The answer is clear: **no per-tool accent colors, no per-tool logos, no per-tool visual identities.** Every tool lives inside the Angkin navy+gold palette. Category differentiation happens through iconography (defined in 2.6), not color.

Why this matters:
- A user who arrives at "SSS Maternity Benefit Calculator" and then navigates to "13th Month Pay Calculator" should feel like they're in the **same place**, not two different apps
- Per-tool colors create a maintenance nightmare (148 unique accent colors? 14 category palettes? Both are unsustainable)
- The Angkin brand mark — that navy circle with the diagonal slash — is the trust signal. Fragmenting it across sub-brands dilutes it.
- Compliance tools need institutional trust, not personality. Navy + gold says "this is authoritative." A rainbow of category colors says "this is a marketplace."

### Exception: Named Flagship Tools

Two tools have established proper names: **TaxKlaro** and **Inheritance Calculator**. These are the only tools that get any visual distinction — and even then, it's minimal:

| Tool | Display Name | Treatment |
|------|-------------|-----------|
| TaxKlaro | TaxKlaro | Wordmark in Plus Jakarta Sans semibold, no unique accent |
| Inheritance | Inheritance Calculator | Wordmark in Plus Jakarta Sans semibold, gold accent retained from existing app |
| All others | Descriptive name (e.g., "SSS Maternity Benefit") | Standard Angkin typography, no unique treatment |

The gold accent on Inheritance is grandfathered because it's already in production and it works within the Angkin palette (gold IS the accent color). TaxKlaro drops its blue (#1D4ED8) and adopts the standard navy.

**Going forward, new tools do NOT get proper names or unique visual identities.** They are "Angkin — [Descriptive Tool Name]".

## Tool Naming Convention

### Page Title Format
```
[Tool Name] — Angkin
```
Example: `13th Month Pay Calculator — Angkin`

### In-App Header Format
```
[Angkin Mark 24px] Angkin  ›  [Category]  ›  [Tool Name]
```
Example: `[⌀] Angkin  ›  Labor  ›  13th Month Pay Calculator`

The breadcrumb trail establishes hierarchy without sub-branding. The tool name is the last breadcrumb, never a standalone brand.

### For Named Flagship Tools
```
[Angkin Mark 24px] Angkin  ›  TaxKlaro
```
Named tools skip the category breadcrumb — they're recognized by name.

## The "by Angkin" Badge

A small, consistent attribution that appears on every tool page. This is NOT a footer logo — it's a trust signal that connects every tool to the platform.

### Badge Anatomy
```
┌─────────────────────────┐
│ [⌀ 16px] by Angkin      │
└─────────────────────────┘
```

- **Mark**: 16px Angkin logo (navy on light, white on dark)
- **Text**: "by Angkin" in DM Sans regular, 12px, neutral-500 (#6B7485)
- **Spacing**: 6px gap between mark and text
- **Background**: none (transparent, sits on any surface)
- **Placement**: Top-right of tool header area, or footer — never both

### CSS

```css
.angkin-badge {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  font-family: var(--font-body);
  font-size: 12px;
  color: var(--neutral-500);
  text-decoration: none;
}

.angkin-badge svg {
  width: 16px;
  height: 16px;
  flex-shrink: 0;
}

.angkin-badge:hover {
  color: var(--navy-600);
}

/* Dark mode */
[data-theme="dark"] .angkin-badge {
  color: var(--neutral-400);
}
[data-theme="dark"] .angkin-badge:hover {
  color: var(--navy-300);
}
```

### When to Show the Badge
- **Always**: On individual tool pages (in the header or footer)
- **Never**: On the platform home page (the Angkin brand is already the page identity)
- **Never**: Inside result cards, PDF exports, or shared results (the result IS the Angkin product)

## Tool Header Pattern

When a user enters a tool, the header establishes context:

### Desktop Header (960px max-width)
```
┌──────────────────────────────────────────────────────────────────┐
│ [⌀ 32px] Angkin    [Search] [🌙] [≡]      [by Angkin badge]    │
├──────────────────────────────────────────────────────────────────┤
│ Angkin  ›  Labor  ›  13th Month Pay Calculator                  │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  13th Month Pay Calculator                                       │  ← Plus Jakarta Sans bold, 28px
│  Compute your guaranteed year-end bonus under PD 851.            │  ← DM Sans regular, 16px, neutral-500
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### Key Elements
- **Nav bar**: 64px height, Angkin logo + wordmark on left, search + theme toggle + menu on right
- **Breadcrumb**: Below nav, 14px, neutral-400, links back to category and home
- **Tool title**: Large, authoritative, Plus Jakarta Sans bold
- **Tool subtitle**: One-line plain-language description of what this tool does
- **No tool-specific logo or icon in the header** — the category icon appears only on the card grid

### For Named Flagship Tools
```
│ Angkin  ›  TaxKlaro                                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  TaxKlaro                                                        │  ← Larger: 32px
│  Philippine Income Tax Optimizer                                  │
│                                                                  │
```

Named tools get a slightly larger title treatment and skip the category breadcrumb.

## Archetype Badges

Each tool card shows its archetype as a small badge. This helps users understand what kind of interaction to expect:

| Archetype | Badge Label | Description for Users |
|-----------|------------|----------------------|
| Single-form calculator | Calculator | Enter values, get a result |
| Decision tree | Eligibility | Answer questions, get a verdict |
| Multi-step wizard | Multi-Step | Walk through a process |
| Comparison engine | Comparison | Compare options side by side |
| Timeline/calendar | Calendar | Track deadlines and due dates |
| Dashboard/tracker | Dashboard | Monitor an ongoing portfolio |
| Document generator | Document | Generate a checklist or form |
| Lookup table | Lookup | Search for a specific value |

Badge CSS:


## Tool-Specific Accent Rule: The Exception

There is **one** scenario where a tool gets a visual accent beyond the standard palette: **featured/promoted tools on the platform home**.

If a tool is seasonally relevant (e.g., "13th Month Pay Calculator" in December, "Annual Income Tax" in April), it can receive a **gold accent border** on its card:

```css
.tool-card--featured {
  border-color: var(--gold-400);
  border-width: 2px;
}

.tool-card--featured::before {
  content: "Timely";
  position: absolute;
  top: -1px;
  right: 12px;
  background: var(--gold-400);
  color: white;
  font-size: 10px;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.08em;
  padding: 2px 8px 3px;
  border-radius: 0 0 var(--radius-sm) var(--radius-sm);
}
```

This is the gold accent doing what it was designed to do — draw selective attention. It's used for 2-4 tools at a time, rotated seasonally.

## Migration Plan

### TaxKlaro
1. Drop blue primary (#1D4ED8) — adopt navy-600 (#1E3A5F)
2. Add "by Angkin" badge to header
3. Add breadcrumb: `Angkin › TaxKlaro`
4. Keep name "TaxKlaro" as a named flagship tool
5. No tool-specific accent color

### Inheritance Calculator
1. Primary already matches (#1E3A5F) — no change
2. Gold accent already matches — retained
3. Add "by Angkin" badge to header
4. Add breadcrumb: `Angkin › Inheritance Calculator`
5. Gold accent is the Angkin system accent, not a tool-specific one

### New Tools (All 146 Others)
1. Use Angkin palette exclusively (navy + gold + neutrals)
2. No custom name — use descriptive name (e.g., "SSS Maternity Benefit Calculator")
3. Include "by Angkin" badge
4. Include category breadcrumb
5. Appear in tool grid with standard card treatment

## Summary of Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Per-tool accent colors | **No** | Doesn't scale to 148. Fragments brand. |
| Per-category colors | **No** | 14 palettes = visual chaos. Icons differentiate. |
| Named sub-brands | **Only TaxKlaro + Inheritance** | Grandfathered. No new named tools. |
| "by Angkin" badge | **Yes, on every tool page** | Trust signal linking back to platform |
| Tool cards on home | **Category icon + name + description + archetype badge** | Consistent, scannable, filterable |
| Featured/seasonal highlight | **Gold border accent, max 2-4 at a time** | Gold doing its job as attention accent |
| Shared result attribution | **12px logo + "angkin.ph"** | Minimal, drives discovery |
| Tool header pattern | **Nav + breadcrumb + title + subtitle** | Establishes hierarchy without sub-branding |

**Total new CSS custom properties: ~25**

*Sub-tool branding defined. The core principle: Angkin is the brand, tools are features. No per-tool visual identity. Category differentiation through icons (defined in 2.6). Named flagships (TaxKlaro, Inheritance) get minimal special treatment. Gold accent reserved for seasonal featured tools.*
