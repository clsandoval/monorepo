## Key Observations for Angkin Platform Design

1. **Primary color ALREADY matches Angkin**: `--primary: #1E3A5F` is the exact Angkin brand navy. Inheritance was built with this palette in mind. This is the canonical reference for the platform color system.

2. **Gold accent (`#C5A44E`) is a strong choice**: Navy + gold reads as professional, authoritative, and premium. This should carry forward to the Angkin platform level. It works beautifully for the sidebar and as a chart accent.

3. **Darker semantic colors**: Inheritance uses deeper reds (`#991B1B` vs TaxKlaro's `#EF4444`), greens (`#166534`), and browns (`#92400E`). This feels more mature/professional. The Angkin system should follow this darker semantic palette.

4. **Font inconsistency with TaxKlaro**: Inter+Lora vs DM Sans+DM Serif Display. The Angkin platform needs to pick ONE pairing. Inter is the safer choice (more readable at small sizes, ubiquitous), but DM Sans has more personality.

5. **More complete token system**: Inheritance has animation tokens, skeleton tokens, a 5-step shadow scale, and sidebar-specific colors that TaxKlaro lacks. The Angkin design system should adopt this more comprehensive approach.

6. **Navy sidebar pattern**: The dark navy sidebar with gold accents is a strong layout pattern for the platform. This could become the standard Angkin navigation treatment.

7. **Missing from both apps**: No spacing scale tokens, no type scale tokens (Inheritance doesn't define explicit `--text-*` variables like TaxKlaro does), no max-width/container tokens.

## Comparison Summary: TaxKlaro vs Inheritance

| Aspect | TaxKlaro | Inheritance | Recommendation for Angkin |
|--------|----------|-------------|--------------------------|
| Primary color | `#1D4ED8` (blue-700) | `#1E3A5F` (deep navy) | **Navy** — it's the brand |
| Accent | None (uses slate) | `#C5A44E` (gold) | **Gold** — professional, distinctive |
| Fonts | DM Sans + DM Serif Display | Inter + Lora | **Decide in 2.3** — both valid |
| Destructive | `#EF4444` (bright red) | `#991B1B` (deep red) | **Deep red** — more professional |
| Radius | `0.5rem` (8px) | `0.625rem` (10px) | **0.5rem** — slightly tighter is better for data-heavy tools |
| Shadows | 3-step (sm/md/lg) | 5-step (xs/sm/md/lg/xl) + sidebar | **5-step** — more flexible |
| Animation tokens | None | 3 durations + 3 easings | **Yes** — standardize |
| Dark mode | Full set | Not defined | **Need to build** |
| Type scale | 6-step explicit vars | None (Tailwind classes) | **Explicit vars** — needed for consistency |
| Sidebar | Not present | Navy + gold | **Adopt** — strong pattern |
| Print styles | None | Times New Roman legal | **Keep** — legal tools need print |
| shadcn style | Default | new-york | **new-york** — tighter, more professional |
