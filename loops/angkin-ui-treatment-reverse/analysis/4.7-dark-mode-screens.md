# 4.7 — Dark Mode Screens

## Overview

Three dark mode mockups at 1280px desktop viewport demonstrating the full dark mode palette from analysis 2.2 in action across the three most important screen types: discovery (platform home), output (results), and input (wizard form).

---

## Mockup 1: Dark Mode Platform Home (`section-04-7-dark-platform-home.png`)

**What it shows**: The Angkin homepage with 3x3 tool card grid in full dark mode.

### Key Dark Mode Adaptations

| Element | Light Mode | Dark Mode |
|---------|-----------|-----------|
| Page background | neutral-50 (#F7F8FA) | navy-950 (#060D18) |
| Nav bar | White with navy text | navy-900 (#0B1628) with off-white text |
| Logo | Navy mark on white | White mark on dark |
| Hero heading | navy-600 (#1E3A5F) | off-white (#E8EDF2) |
| Tool cards | White card, navy border | surface-1 (#101D30), navy border (#1E2D42) |
| Card text | neutral-900 heading, neutral-500 body | off-white heading, neutral-400 body |
| "Timely" badge | Gold on white | Gold on dark — pops beautifully |
| Category tabs | Navy-600 active | Navy-400 (#4D77A3) active |
| Nav active link | Navy-600 underline | Gold (#C5A44E) highlight |

### Design Observations

- The gold "Timely" badge stands out more in dark mode — gold on dark navy is one of the palette's strongest combinations (8.4:1 contrast AAA)
- Tool cards create a clear layered elevation: page (#060D18) → card (#101D30) with #1E2D42 borders
- The nav bar subtly separates from the page background by using navy-900 (#0B1628) — one step lighter than the page base
- Category filter tabs use navy-400 for the active indicator — visible without being overwhelming

## Mockup 2: Dark Mode TaxKlaro Results (`section-04-7-dark-taxklaro-results.png`)

**What it shows**: The tax regime comparison — the most data-dense, highest-stakes screen in the platform.

### Key Dark Mode Adaptations

| Element | Light Mode | Dark Mode |
|---------|-----------|-----------|
| Regime cards | White bg | surface-1 (#101D30) bg |
| Recommended card | success-50 bg, success-500 border | #071F16 bg, #059669 border |
| "Recommended" badge | Green on light green | Bright green (#34D399) on dark green |
| Peso amounts | navy-600 monospace | navy-200 (#A8BBD4) monospace |
| Savings text | success-500 | bright green (#34D399) |
| Breakdown table | Alternating white/neutral-50 | Alternating surface-0/surface-1 |
| Chart bars | Navy + gold | Navy-400 + gold-300 (lighter variants) |
| Breadcrumb | neutral-500 text | neutral-400 text |

### Design Observations

- The "result card moment" works powerfully in dark mode — large monospace peso amounts in light navy (#A8BBD4) against dark surfaces create dramatic contrast
- The recommended card's green tint (#071F16) is barely perceptible as colored — just enough to distinguish it from standard cards without being garish
- Chart colors shift to lighter variants (navy-400, gold-300, teal-300) for visibility on dark backgrounds
- The breakdown table with alternating dark rows creates readable data density without eye strain
- Savings amounts in bright green (#34D399) pop strongly — this is the "save money" moment and it deserves visual emphasis

## Mockup 3: Dark Mode Wizard Step (`section-04-7-dark-wizard-step.png`)

**What it shows**: The inheritance wizard "Add Family Member" form — the primary input pattern.

### Key Dark Mode Adaptations

| Element | Light Mode | Dark Mode |
|---------|-----------|-----------|
| Sidebar | navy-600 | navy-900 (#0B1628) — darker than content |
| Sidebar active step | Gold dot + white text | Gold dot + white text (unchanged) |
| Sidebar completed step | Green check | Green check (#34D399) |
| Sidebar upcoming steps | White text, reduced opacity | Muted gray (#6B7485) |
| Content area | White card | surface-1 (#101D30) |
| Form labels | neutral-700 | neutral-400 (#8C95A3) |
| Input fields | White bg, neutral-200 border | surface-2 (#152438) bg, #1E2D42 border |
| Input focus | Navy-600 border + ring | Navy-400 (#4D77A3) border + glow |
| Placeholder text | neutral-400 | neutral-500 (#6B7485) |
| Dropdown | White bg | surface-2 (#152438) bg |
| Primary button | navy-600 bg, white text | navy-400 bg, white text |
| Ghost button | navy-600 border | #1E2D42 border, off-white text |

### Design Observations

- The sidebar strategy works: sidebar (#0B1628) is darker than content area (#101D30), preserving the hierarchy from light mode
- Gold wizard step indicator provides consistent wayfinding in both modes
- Input fields use surface-2 (#152438) — one layer above the card surface — creating the same "inset" feel as light mode inputs on white
- The focus state border glow in navy-400 is visible without being harsh — opposite of light mode's darken pattern (hover/focus goes lighter in dark mode)
- Dropdown overlay shows proper dark mode elevation: sits on surface-2 above the form surface

## Cross-Cutting Dark Mode Patterns

### What works well in dark mode:
1. **Gold accent** — the strongest improvement over light mode; gold on dark navy is premium and luxurious
2. **Monospace peso amounts** — large light-colored numbers on dark surfaces create dramatic data moments
3. **Semantic color backgrounds** — barely-tinted dark surfaces (success at #071F16, error at #1F0A0A) are subtle and professional
4. **Layered elevation** — the 4-step surface system (#060D18 → #0B1628 → #101D30 → #152438) creates depth without borders

### What needs care:
1. **Logo inversion** — must swap navy fill → white fill, with navy-950 slash (not pure black)
2. **Chart colors** — must shift to lighter variants (400→300 level) or they disappear
3. **Borders** — must be subtle (#1E2D42) not heavy; dark mode relies on elevation differences more than border lines
4. **Text hierarchy** — off-white (#E8EDF2) not pure white for primary text; avoids halation
