## Design Decisions

- Used live HTML/CSS for all component examples (not images) — more accurate than mockups
- Color swatches use the actual hex values so they're pixel-accurate
- Type specimens show real text with exact font-family, size, weight, letter-spacing
- Buttons and inputs are rendered as real HTML elements with inline styles matching the design tokens
- Result card and comparison table use realistic Philippine compliance data
