# 2.1 — Color System

## Design Direction

**Navy-undertoned institutional palette.** Every gray, every tint, every surface carries a whisper of the #1E3A5F navy. This creates a cohesive, branded atmosphere rather than the generic Tailwind Slate that most apps default to. The gold accent (#C5A44E) is used sparingly — it's a scalpel, not a paintbrush.

The palette must serve 148 compliance calculators. That means:
- Semantic colors (success/warning/error/info) must be instantly readable
- The peso amount display moment is the most important color decision
- Neutral surfaces must stay calm — the data is the star
- Navy branding must not compete with semantic meaning

| `--navy-150` | `#C2D0E2` | 213° 35% 83% | Borders on light backgrounds |
| `--navy-200` | `#A8BBD4` | 213° 37% 75% | Disabled text on dark, secondary borders |
| `--navy-300` | `#7A99BE` | 213° 35% 61% | Placeholder text, tertiary elements |
| `--navy-400` | `#4D77A3` | 213° 36% 47% | Secondary text, icons |
| `--navy-500` | `#2D5A85` | 213° 49% 35% | Medium emphasis — links on light bg |
| `--navy-600` | `#1E3A5F` | 213° 52% 25% | **THE BRAND — primary buttons, headings, logo** |
| `--navy-700` | `#172E4D` | 213° 55% 20% | Hover state for primary elements |
| `--navy-800` | `#11223A` | 213° 55% 15% | Active/pressed state, dark surfaces |

### Key Decision: #1E3A5F is 600, not 500

Most design systems place their "primary" at the 500 or 600 level. Navy #1E3A5F is naturally dark (25% lightness), which maps to 600 in a typical scale. This means:
- **Light mode**: Navy-600 is the primary action/brand color (4.5:1+ contrast on white ✓)
- **Dark mode**: Navy-400 or Navy-300 becomes the primary (adequate contrast on dark ✓)
- Tints above 600 provide surfaces, borders, and hover states
- Shades below 600 provide pressed states and dark mode backgrounds

## Accent Gold Scale

The gold #C5A44E is the premium/professional accent. Used for: highlighted results, recommended badges, active sidebar items, and chart accents.

| Token | Hex | Usage |
|-------|-----|-------|
| `--gold-50` | `#FBF7ED` | Gold tint background (award cards, featured items) |
| `--gold-100` | `#F5ECD4` | Gold surface |
| `--gold-200` | `#EBDAAB` | Gold border |
| `--gold-300` | `#DECA85` | Gold secondary |
| `--gold-400` | `#C5A44E` | **THE ACCENT — badges, highlights, sidebar active** |
| `--gold-500` | `#A68A3D` | Gold on white (better contrast — 3.4:1) |
| `--gold-600` | `#87702F` | Gold text on white (4.8:1 contrast ✓) |
| `--gold-700` | `#685522` | Dark gold — strong text on white (7.3:1 ✓) |
| `--gold-800` | `#4A3C17` | Deepest gold |

### Gold Usage Rules
- **Never use gold-400 for text on white** — fails WCAG AA (3.4:1 contrast)
- **Gold-600 or gold-700 for text** — passes AA
- **Gold-400 for non-text elements** — badges, borders, icons, chart fills
- **Gold-50 for surfaces** — "recommended" or "featured" card backgrounds
- **Gold on navy**: Gold-400 on navy-600 = 3.6:1 — use only for large text or decorative. Gold-300 on navy-600 = better for readability.

## Neutral Scale (Navy-Undertoned)

This is NOT Tailwind Slate. It's a custom neutral with a subtle navy undertone (hue ~215°, very low saturation). This makes neutrals feel cohesive with the brand rather than generic.

| Token | Hex | Sat% | Usage |
|-------|-----|------|-------|
| `--neutral-0` | `#FFFFFF` | 0% | Pure white — card surfaces |
| `--neutral-50` | `#F7F8FA` | 14% | Page background (light mode) |
| `--neutral-100` | `#EEF0F4` | 14% | Subtle surface distinction |
| `--neutral-150` | `#E3E6EC` | 12% | Input backgrounds |
| `--neutral-200` | `#D5D9E1` | 12% | Borders, dividers |
| `--neutral-300` | `#B8BEC9` | 10% | Disabled elements |
| `--neutral-400` | `#8C95A3` | 8% | Placeholder text |
| `--neutral-500` | `#6B7485` | 8% | Secondary text |
| `--neutral-600` | `#505868` | 7% | Body text (secondary) |
| `--neutral-700` | `#374050` | 8% | Body text (primary alternative) |
| `--neutral-800` | `#1F2735` | 12% | Headings (non-brand) |
| `--neutral-900` | `#111827` | 15% | Strongest text |
| `--neutral-950` | `#0A0F18` | 18% | Near-black |

### Why Custom Neutrals?

TaxKlaro and Inheritance both use Tailwind Slate, which has a blue-gray undertone that *almost* works with navy. But a custom neutral with a controlled navy undertone creates a noticeably more polished, intentional feel. The difference is subtle but cumulative — across 148 tools, it reads as "designed" rather than "defaulted."

## Palette Summary

The Angkin color system is:
- **3 scales**: Navy (brand), Gold (accent), Neutral (navy-undertoned grays)
- **4 semantic colors**: Success (green), Warning (amber), Error (red), Info (teal)
- **6 chart colors**: Derived from the scales above
- **10 compliance tokens**: Peso amounts, regime comparisons
- **~20 shadcn/ui mappings**: Component-level semantic layer
- **~10 sidebar tokens**: Navy sidebar with gold highlights

Total: ~80 unique CSS custom properties covering every color need across 148 compliance tools.
