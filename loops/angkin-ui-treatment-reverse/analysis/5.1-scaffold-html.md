# 5.1 — Scaffold `output/ui-treatment-deck.html`

## What Was Built

The HTML scaffold at `output/ui-treatment-deck.html` — a self-contained, single-file design reference document with all Angkin design tokens baked into inline CSS.

## Structure

### Cover Page
- Full-viewport navy hero with inverted 2C logo (inline SVG, 128px)
- Title "Angkin" in Plus Jakarta Sans 4rem/800
- Subtitle and metadata line
- Subtle radial gradient accents (gold + navy tints) for depth

### Table of Contents
- 4-column grid layout with gold section numbers + linked section titles
- Sticky positioning with compact mode on scroll (JS-driven)
- Anchor links to all 12 sections

### 12 Sections
Each section follows the same anatomy:
1. **Section number** — gold overline in IBM Plex Mono, uppercase
2. **Section title** — Plus Jakarta Sans 2.25rem/700, navy-600
3. **Section description** — DM Sans 15px body, neutral-600, max-width 600px
4. **Content area** — 1120px max-width, placeholder for 5.2 to populate

Sections alternate backgrounds (neutral-50 / neutral-0) for visual rhythm.

### Footer
- Navy-600 background, inverted logo, metadata

## CSS Framework (~250 CSS custom properties)

All design tokens from Waves 1-2 are implemented as CSS custom properties:

### Colors (~80 properties)
- Navy scale (50-950, 12 steps)
- Gold scale (50-800, 9 steps)
- Neutral scale (0-950, 13 steps)
- Semantic colors (success/warning/error/info, 5 stops each)
- Chart colors (6)
- Compliance-specific tokens (4)

### Typography (~30 properties)
- 3 font families (heading, body, mono) loaded via Google Fonts
- 10-step type scale (hero → overline)
- Line heights, letter spacing, weights
- 4 peso amount sizes

### Spacing & Layout (~55 properties)
- 16-step spacing scale
- Border radius (7 steps)
- Shadows (5 levels, navy-tinted)
- Transitions (3 durations + 1 easing)

### Reusable CSS Classes

Utility classes for the deck itself:
- `.content-grid` with 2/3/4-column variants
- `.content-block` with dark/navy variants
- `.mockup` with mobile/browser variants (browser chrome effect)
- `.swatch-row` + `.swatch` for color palette display
- `.code-block` with syntax highlighting classes
- `.type-specimen` for font display
- `.token-table` for design token documentation
- `.spacing-demo` for spacing visualization
- `.placeholder-content` for sections awaiting 5.2 population

## Font Loading

Google Fonts CDN for the three font families:
- Plus Jakarta Sans (200-800 variable)
- DM Sans (100-1000 variable)
- IBM Plex Mono (400, 500, 600)

## Design Decisions for the Deck Itself

- **1280px viewport target** — `<meta name="viewport" content="width=1280">` locks the design reference width
- **Alternating section backgrounds** — odd sections neutral-50, even sections white, creates visual separation
- **96px section padding** — generous breathing room between sections
- **720px section header max-width** — prevents long descriptions from becoming wide
- **1120px section content max-width** — matches the platform's full-width container
- **Inline SVG logos** — canonical mark embedded directly, no external image dependency for the core brand
- **No external CSS** — everything inline for portability
