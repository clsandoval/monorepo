# 5.3 — Final Polish: QA & Verification

## Summary

Final QA pass on `output/ui-treatment-deck.html`. Replaced 22 broken `<img>` tags (referencing non-existent `raw/*.png` mockups) with styled CSS-only wireframe blocks. Verified all 12 sections render correctly via Playwright full-page screenshot.

## Issues Found & Fixed

### Broken Images (22 total)
The Wave 4 aspects (4.1–4.7) documented mockup generation in their analysis files, but the `raw/` directory contains no PNG files — the gemini-image-gen outputs were either not committed or generated in a different environment. The logo reference image (`docs/brand/angkin/direction-02c-radical-clarity.png`) does not exist in this CI environment.

**Fix**: Replaced all 22 `<img>` tags with `.mockup-wireframe` CSS blocks that:
- Use the navy-950 → navy-800 gradient background from the design system
- Display a subtle 40px grid overlay (matching the 4px base unit × 10)
- Show relevant SVG icons (Angkin logo, tool-specific icons)
- Include descriptive titles and design specs for each screen
- Mobile mockups use taller `--mobile` variant (480px min-height)

### New CSS Added
- `.mockup-wireframe` — base wireframe container with navy gradient + grid
- `.mockup-wireframe--mobile` — taller variant for phone mockups
- `.mockup-wireframe__icon` — 48px circle with navy fill + border
- `.mockup-wireframe__title` — 14px heading in navy-200
- `.mockup-wireframe__desc` — 11px mono description in navy-400
- `.mockup-wireframe__blocks` — abstract shape blocks suggesting layout
