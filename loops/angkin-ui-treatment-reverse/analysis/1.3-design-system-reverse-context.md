# 1.3 — Design System Reverse Loop Context Extraction

## Source
`loops/angkin-design-system-reverse/analysis/` — 37 analysis files from a 27-aspect loop exploring 10 design system options for Angkin.

## Critical Context: User Selected 2C Radical Clarity Logo, NOT Warm Stripe

The design system loop recommended **Hybrid A "Warm Stripe"** (Option 3 warmth + Option 4 tokens + Option 8 mobile patterns, ~52/60 estimated). However, the user selected the **2C Radical Clarity logo** — a circle with diagonal slash forming a negative-space 'A', deep navy (#1E3A5F) on white.

This means the treatment deck must **reconcile a brand mark that signals institutional precision** with the broader Angkin audience needs identified in the research. The logo's deep navy anchors the entire system.

## Key Research Findings for the Treatment Deck

### 1. Audience Segments (7 behavioral archetypes)

| Segment | Core Need | Device | Best Design Signals |
|---------|-----------|--------|---------------------|
| A: Scared first-timer (Mang Rolly, 57) | One clear answer | Mobile | Large text, plain language, one-thing-at-a-time |
| B: HR/payroll staff (Ate Leny) | Speed + auditability | Desktop | Fast to result, copyable, consistent |
| C: OFW on mobile (Jasmine, 26) | Trusted number, shareable | Mobile (spotty) | Screenshot-ready, fast load, on-their-side tone |
| D: Small business owner | Quick compliance check | Mixed | Authoritative, understandable explanations |
| E: Accountant/bookkeeper (Mel, 38) | Batch speed, keyboard nav | Desktop | Dense info, keyboard shortcuts, export |
| F: Young professional (Jolo, 27) | Visual quality, rights awareness | Mixed | Design-literate aesthetic, shareable |
| G: Retiree (Rosario, 58) | Absolute trust, citable result | Tablet | Institutional signals, large text, no flash |

**Key insight**: No single option served all 7 segments. The 2C navy logo naturally anchors toward segments B, D, G (trust/authority) while needing extra warmth to serve A, C, F (approachability/shareability).

### 2. Tool Archetypes (148 tools)

| Archetype | Count | % | Design Priority |
|-----------|-------|---|----------------|
| Single-form calculator | 64 | 43% | **Core archetype** — result moment is THE design challenge |
| Decision tree | 22 | 15% | Wizard-like flow, binary outcomes |
| Multi-step wizard | 18 | 12% | Progress visibility, partial saves |
| Comparison engine | 14 | 9% | Side-by-side, clear winner highlight |
| Timeline/calendar | 11 | 7% | Color-coded urgency |
| Dashboard/tracker | 10 | 7% | Repeat-use, bulk operations |
| Document generator | 5 | 3% | Print-ready output |
| Lookup table | 4 | 3% | Search-first, single clear answer |

**Key insight**: 43% of tools are single-form calculators. The "result moment" — when the user hits Compute and sees their number — is the most important UX moment in the entire system. The treatment deck MUST nail the result card design.

### 3. Option 2 (Radical Clarity) Spec — Closest to Selected Logo Direction

Since the user chose the radical clarity logo, Option 2's design spec is the most relevant starting point. Key elements:

- **Philosophy**: Content is the interface. Decoration is a tax on comprehension.
- **Colors**: Near-monochrome with single accent. Near-black #1A1918 text, teal #00766A accent.
- **Typography**: Public Sans (body) + Overpass Mono (result numbers). 19px minimum body text.
- **Spatial**: 640px max-width, single-column, 40px gutters desktop / 20px mobile. 5px base spacing unit.
- **Components**: Square corners (border-radius: 0), 2px black input borders, no placeholder text.
- **Focus**: Yellow #FFD000 focus ring, 3px outline offset — from gov.uk.
- **Result display**: Large monospace number (52px desktop / 38px mobile), breakdown table, law citation.
- **Accessibility**: WCAG AAA target, 19:1 contrast ratio, 48px min touch targets.
- **Animation**: Essentially none (150ms page fade, 200ms result reveal only).
- **Dark mode**: Not originally planned for Option 2.
- **Icons**: None by default (text characters only: ←, ✓, ⚠, ₱).

**BUT the treatment deck extends beyond pure Option 2** because:
1. The user wants dark mode (Section 10 of the deck)
2. The user wants iconography (Section 9)
3. The user wants sub-tool branding with accent colors (Section 7)
4. The platform needs navigation patterns beyond single-tool (Section 8)
5. The user wants mobile treatment (Section 11)

### 4. Cross-Option Insights to Incorporate

From the comparison matrix and other options, these ideas should inform the treatment deck:

| From Option | What to Adopt | Why |
|-------------|--------------|-----|
| Option 2 (Radical Clarity) | Form structure, accessibility rigor, result display | Aligns with selected logo direction |
| Option 4 (Stripe-Grade) | Token architecture, semantic versioning, developer ergonomics | Necessary for 148-tool scale |
| Option 3 (Filipino Warmth) | Domain accent colors, bilingual label patterns | Cultural fit for Philippines audience |
| Option 8 (Mobile-First) | Bottom CTA, touch targets, card-first on mobile | 85% mobile traffic reality |
| Option 9 (Soft Institutional) | Trust signals for high-stakes tools | Retiree/business owner segments |
| Option 10 (Bold Geometric) | Result card as shareable moment | Viral growth through screenshots |

### 5. Competitive Landscape

Philippine digital compliance tools are uniformly hostile:
- **BIR eFPS/eBIR**: Gray, dense, impenetrable
- **SSS portal**: Slow, confusing, mobile-hostile
- **PhilHealth**: Bureaucratic, no clear computation

Angkin's competitive advantage is quality gap — ANY well-designed tool will stand out. The 2C navy logo's institutional clarity is an asset here: it signals "serious and trustworthy" while the execution quality signals "modern and competent."

### 6. Scoring Context for 2C Direction

Option 2 (Radical Clarity) scored 43/60 in the comparison matrix:
- **Strengths**: Accessibility (5), Mobile (5), Simplicity (5), Scalability (5), Dev Ergonomics (5)
- **Weaknesses**: Friendliness (2), Filipino Cultural Fit (2), Visual Memorability (1), Distinctiveness (2)

The treatment deck must **keep the strengths while mitigating the weaknesses** — the navy logo is more distinctive than gov.uk's plain approach, and the extended palette + sub-tool branding + dark mode can add memorability and warmth without sacrificing clarity.

## Implications for the Treatment Deck

### Color System (Section 2)
- Primary: #1E3A5F (from Inheritance app, matches logo)
- Need: Full tint/shade scale, 14 domain accent colors, semantic colors, dark mode palette
- Inherit: Option 2's semantic colors as starting point, but warmer than pure gov.uk

### Typography (Section 3)
- TaxKlaro uses DM Sans/Serif Display; Inheritance uses Inter/Lora — **neither matches** Option 2's Public Sans recommendation
- Decision needed: Keep existing app fonts or unify? Treatment deck should make a clear choice
- Monospace for numbers is non-negotiable (both apps already use monospace in results)

### Component Library (Section 5)
- Both apps use shadcn/ui (Radix primitives) + Tailwind 4 — keep this stack
- Both use Lucide icons (20-30 icons each) — Lucide is the icon library choice
- Unify: shadcn component tokens should flow from Angkin design tokens

### Navigation (Section 8)
- Neither app has platform-level navigation yet — this is greenfield for the treatment deck
- Must serve both single-tool landing (SEO) and platform exploration (discovery)

### Result Moment (Section 6)
- Both apps have result displays but no shared pattern
- This is the #1 design priority per the archetype analysis

### Existing Design Tokens to Reconcile
- TaxKlaro: blue-700 primary (#1D4ED8) — diverges from Angkin navy
- Inheritance: #1E3A5F primary — already matches Angkin navy
- Both use Tailwind Slate neutrals — consistent, keep this
- Inheritance has gold accent #C5A44E — could become sub-tool branding
