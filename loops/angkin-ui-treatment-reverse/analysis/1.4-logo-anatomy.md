# 1.4 — Logo Anatomy: 2C Radical Clarity Mark

## The Mark

The Angkin brand mark is the **2C Radical Clarity** logo: a circle with a diagonal slash that carves a negative-space **'A'** from the form. Rendered in deep navy (#1E3A5F) on white, or inverted for dark contexts.

The mark communicates:
- **Precision** — geometric, clean, mathematically derived
- **Clarity** — the 'A' emerges from absence, not addition
- **Authority** — the navy signals institutional trust (government, finance, law)
- **Modernity** — abstract enough to feel contemporary, not a literal illustration

---

## Geometric Construction

### Core Geometry
- **Outer form**: Perfect circle
- **Slash**: A diagonal line cutting from upper-right to lower-left, creating two regions
- **The 'A'**: Formed by the negative space where the slash meets the circle boundary — the triangular void at the bottom reads as the crossbar-less 'A' of "Angkin"
- **Stroke weight**: The slash width is approximately 1/6th of the circle diameter
- **Slash angle**: ~135° from horizontal (upper-right to lower-left)

```
└─────────────────┘
```

### Proportions
- Circle diameter = **1 unit** (reference unit for all measurements)
- Slash width = **1/6 unit** (0.167)
- The 'A' negative space occupies roughly **25-30%** of the circle area

## Clear Space Rules

Minimum clear space around the mark = **1/4 of the circle diameter** on all sides.

```
        ← 0.25d →
       ┌──────────┐
  ↑    │          │
 0.25d │  (LOGO)  │
  ↓    │          │
       └──────────┘
```

This means:
- **Favicon (16×16px)**: Logo occupies 12×12px, 2px clear space
- **Nav (32×32px)**: Logo occupies 24×24px, 4px clear space
- **Hero (128×128px)**: Logo occupies 96×96px, 16px clear space

- **Digital**: 16px diameter (favicon). Below this, the slash and 'A' negative space become indistinguishable.
- **Print**: 10mm diameter minimum.

## Color Variants

### Primary (Light Background)
- **Mark**: #1E3A5F (deep navy) on white/light background
- **Usage**: Default. Use this in 90%+ of contexts.

### Inverted (Dark Background)
- **Mark**: #FFFFFF (white) on dark background
- **Usage**: Dark mode, navy hero banners, dark cards
- **Alt**: #E8EDF2 (navy-50 tint) on dark backgrounds for softer appearance

### Monochrome
- **Black**: #000000 on white — for print, fax, stamp contexts
- **White**: #FFFFFF on black — for high-contrast dark contexts

### On Colored Backgrounds
- **On navy (#1E3A5F)**: White mark — creates "seal" effect
- **On accent/semantic colors**: White mark preferred; ensure 4.5:1 contrast minimum
- **Never**: Do not place navy mark on medium-value colors where contrast is insufficient

## Logo + Wordmark Lockup

### Horizontal Lockup (Primary)
```
[MARK] · Angkin
```
- Mark and wordmark separated by 0.5× mark diameter
- Wordmark in **semibold** weight of the heading font
- Wordmark baseline aligns to mark's vertical center
- Wordmark color matches mark color

### Stacked Lockup (Compact)
```
 [MARK]
 Angkin
```
- Wordmark centered below mark
- Gap = 0.25× mark diameter
- Used when horizontal space is limited

### With Tagline
```
[MARK] · Angkin
Philippine Compliance Tools
```
- Tagline in regular weight, smaller size (60% of wordmark size)
- Tagline in lighter color (#64748B on light, #94A3B8 on dark)

## What NOT To Do

These rules protect the mark's integrity:

1. **Don't stretch or distort** — The circle must remain a perfect circle
2. **Don't rotate** — The slash angle is fixed; rotating the entire mark changes the 'A' reading
3. **Don't add effects** — No drop shadows, glows, bevels, gradients, or 3D effects
4. **Don't change the slash** — Don't thicken, thin, or change the angle
5. **Don't recolor with gradients** — Solid fill only
6. **Don't place on busy backgrounds** — The mark needs clean space to read
7. **Don't outline** — The mark is always filled, never stroked/outlined
8. **Don't add elements inside** — No text, icons, or decoration within the circle
9. **Don't crop** — The full circle must always be visible
10. **Don't pair with competing logos at same size** — Angkin mark should be dominant

## Context-Specific Usage

### Favicon
At 16px, the mark should use the standard SVG. Modern browsers support SVG favicons:
```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
```

### Navigation Bar
- Horizontal lockup: 32px mark + "Angkin" wordmark
- Mark acts as home link
- On scroll, mark can reduce to 24px

### Hero / Landing
- 80–128px mark, centered or left-aligned
- Can use a subtle entrance animation: circle draws in (stroke-dasharray), then slash reveals

### Sub-Tool Attribution ("by Angkin")
- 20px mark + "by Angkin" in small text
- Used in footer or header of individual tool pages (TaxKlaro, Inheritance, etc.)
- Lighter weight: #64748B text color on light bg

### Loading State
- Mark can animate: circle draws clockwise, then slash sweeps diagonally
- Keep animation under 800ms
- Use CSS `stroke-dasharray` / `stroke-dashoffset` animation
