# 3.4 — Navigation

## Design Direction

**Platform-level nav with two modes: horizontal top bar (public/tool pages) and sidebar (dashboard/authenticated views).** Angkin's 148 tools create a navigation challenge that most design systems never face: users need to find tools by category, navigate within multi-step wizards, and understand where they are in a 14-domain hierarchy — all while the nav itself stays invisible enough that the tool content (forms, results) remains the star.

The existing apps (TaxKlaro, Inheritance) both use a sidebar-first layout with mobile drawer. This works for authenticated dashboard views. But the platform home and individual tool pages (which are public-facing) need a lighter horizontal top bar. The Angkin navigation system defines both patterns and when to use each.

---

## Navigation Architecture

### Two Navigation Modes

| Mode | When | Desktop | Mobile |
|------|------|---------|--------|
| **Top Bar** | Public pages: platform home, tool landing, tool form/results, about, pricing | Horizontal nav bar, 64px height | Hamburger → slide-in sheet |
| **Sidebar** | Authenticated views: dashboard, saved computations, client management, settings | 256px sidebar + top utility bar | Hamburger → slide-in drawer |

### Why Two Modes?

- **Public tool pages** are single-purpose. A sidebar wastes 256px of viewport on links the user doesn't need. A compact top bar preserves content width for forms and results.
- **Dashboard views** have complex multi-section navigation (computations, clients, deadlines, settings). A sidebar makes these sections scannable without click-through.
- **Both apps already use sidebar** for their authenticated views. The top bar is net-new for the platform shell.

## Top Bar (Public Pages)

The primary navigation for unauthenticated users and public tool pages.

### Desktop Top Bar (≥ 1024px)

```
┌──────────────────────────────────────────────────────────────────────────┐
│  [⌀ 28px] Angkin           Tools ▾   About   Pricing      [🔍] [☀/🌙] │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**Height**: 64px (`--nav-height-desktop`)
**Background**: `var(--neutral-0)` (white) with `var(--border)` bottom border (1px)
**Position**: `sticky` top, `z-index: var(--z-sticky)`
**Content max-width**: `var(--content-full)` (1120px), centered
**Padding**: `0 var(--container-padding-desktop)` (32px)

### Desktop Top Bar Anatomy

| Element | Spec |
|---------|------|
| **Logo lockup** | 28px mark + "Angkin" in Plus Jakarta Sans 600 weight, 18px, navy-600. Gap: 10px. Links to home. |

| **"Tools" dropdown** | Triggers a mega-menu/dropdown on hover with category grouping (see below). |
| **Search icon** | Phosphor `ph-magnifying-glass`, 20px, neutral-500. Opens search overlay on click. |
| **Theme toggle** | Phosphor `ph-sun` / `ph-moon`, 20px, neutral-500. Toggles light/dark. |
| **CTA button** (optional) | "Sign In" — secondary button (ghost variant), height 36px. Only shown when auth exists. |

## Breadcrumbs

Breadcrumbs appear on all tool pages, below the top bar. They establish the user's location in the Angkin hierarchy. This is a net-new pattern — neither existing app implements breadcrumbs yet.

### Breadcrumb Format

```
Angkin  ›  [Category]  ›  [Tool Name]
```

For named flagship tools:
```
Angkin  ›  TaxKlaro
```

### Desktop Breadcrumb

```
┌──────────────────────────────────────────────────────────────────────────┐
│  Angkin  ›  Labor  ›  13th Month Pay Calculator                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**Height**: auto (padding-based)
**Background**: `var(--neutral-50)` — subtle surface distinction from white top bar
**Padding**: `var(--space-2) 0` (8px vertical)
**Content max-width**: Same as page content container

### Breadcrumb States

| Element | Color | Weight | Clickable |
|---------|-------|--------|-----------|
| "Angkin" (home) | `neutral-400` | 400 | Yes → platform home |
| Separator `›` | `neutral-300` | 400 | No |
| Category | `neutral-400` | 400 | Yes → category filter on home |
| Current page (tool name) | `neutral-600` | 500 | No (current location) |

## Anti-Patterns

Things NOT to do in Angkin navigation:

1. **No bottom tab bars** — This is a web platform, not a native app. Bottom bars conflict with browser chrome and feel wrong for 148 tools.
2. **No nested sidebars** — One level of sidebar navigation only. If a tool needs sub-navigation, use tabs within the content area.
3. **No icon-only nav on desktop** — The collapsed sidebar (64px) is NOT implemented. Every nav item must have a text label. The sidebar is full-width (256px) or hidden (mobile).
4. **No animated hamburger-to-X** — The hamburger icon is `ph-list`, the close icon is `ph-x`. They don't morph. Keep it simple.
5. **No transparent/hero-overlapping top bar** — The top bar is always opaque (with blur). No "transparent on hero, solid on scroll" patterns. This is a compliance platform, not a marketing site.
6. **No breadcrumb overflow menus** — Breadcrumbs are always 3 levels max (Angkin › Category › Tool). They fit. No collapsing/truncating intermediate levels.
7. **No sticky sidebar** — The sidebar is `position: fixed`, not `position: sticky`. It doesn't scroll with the page.
8. **No right-side navigation** — All navigation is top or left. Nothing on the right side of the viewport. RTL layout is not in scope.

## Summary of Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Navigation modes | **Top bar (public) + Sidebar (authenticated)** | Public tools need max content width; dashboards need persistent nav |
| Top bar height | **64px desktop, 56px mobile** | Established in spacing system, matches both existing apps |
| Top bar bg | **Opaque white with blur** | Compliance needs visual stability, not flashy transparency |
| Sidebar bg | **Navy-600** | Brand immersion for authenticated views |
| Active sidebar indicator | **3px left border, gold-400** | Carries forward from both apps + uses gold accent purposefully |
| Breadcrumbs | **Always on tool pages, 3 levels max** | New pattern — establishes platform hierarchy |
| Mobile pattern | **Left-slide sheet, 280px, backdrop** | Consistent with both existing apps' drawer pattern |
| Tab bar | **Horizontal scroll, 2px bottom active indicator** | Categories on home, sub-sections in tools |
| Tools dropdown | **Mega-menu, 720px, 3-column categories** | 148 tools need structured discovery |
| Bottom tab bar | **No** | Web platform, not native app |
| Icon-only collapsed sidebar | **No** | Always show labels — accessibility + clarity |

**Total new CSS custom properties: ~25**
