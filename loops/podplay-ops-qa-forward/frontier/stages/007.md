- `loops/podplay-ops-qa-forward/spec/qa-fixes-spec.md` § F08

## Instructions
1. Create `apps/podplay/src/components/ui/SearchableSelect.tsx`
2. Build a combobox component with these props:
```typescript
interface SearchableSelectProps {
  options: { value: string; label: string }[];
  value: string;
  onChange: (value: string) => void;
  placeholder?: string;
  disabled?: boolean;
}
```
3. Implementation approach: Use Radix UI Popover (already in deps) with a filtered list pattern:
   - Text input that filters options as user types
   - Dropdown list below the input showing filtered matches
   - Click or Enter to select an option
   - Escape to close dropdown
   - Arrow keys to navigate the list
   - When an option is selected, show its label in the input and call onChange with value
   - When the input is focused and empty, show all options
4. Style with Tailwind classes matching existing UI (border-input, bg-background, etc.)
5. Export as named export
