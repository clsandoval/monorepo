# Stage 016 — Redirect Non-Intake Projects from Intake Route (F04)

## Spec Reference
- `loops/podplay-ops-qa-forward/spec/qa-fixes-spec.md` § F04

## Instructions
1. Edit `apps/podplay/src/routes/_auth/projects/$projectId/intake.tsx`
2. After loading the project data, check `project_status`:
   - If NOT `'intake'`, redirect to the appropriate page using `useNavigate` or `redirect` in the loader
   - `'procurement'` → redirect to `/projects/${id}/procurement`
   - `'deployment'` → redirect to `/projects/${id}/deployment`
   - `'financial_close'` or `'completed'` → redirect to `/projects/${id}/financials`
3. This prevents users from manually navigating to `/projects/xyz/intake` when the project has already moved past intake
