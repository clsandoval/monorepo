## Pattern Reference

## Instructions
1. Create `apps/podplay/src/components/wizard/financials/RecurringFeesTab.tsx`
2. Props: `{ projectId: string }`
3. On mount: fetch `supabase.from('recurring_fees').select('*').eq('project_id', projectId).order('created_at')`
4. Table columns: Label, Amount, Frequency, Start Date, End Date, Vendor, Active
5. "Add Fee" button opens modal form with fields:
   - Label (text, required)
   - Description (text, optional)
   - Amount (number, required, min 0)
   - Frequency (select: monthly/quarterly/annually, default monthly)
   - Start Date (date, required)
   - End Date (date, optional — null = ongoing)
   - Vendor (text, optional)
   - Notes (text, optional)
6. Edit/Delete per row (same pattern as other settings)
7. Summary row at bottom: "Total Monthly Recurring: $X"
   - Calculation: sum of all active fees normalized to monthly
   - monthly → amount
   - quarterly → amount / 3
   - annually → amount / 12
