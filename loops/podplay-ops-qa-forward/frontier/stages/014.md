## Instructions
1. Edit `apps/podplay/src/routes/_auth/projects/$projectId/intake.tsx`
2. On mount: fetch `project.wizard_step` from Supabase and use it to initialize `useState`
   - `const { data: project } = await supabase.from('projects').select('wizard_step, project_status').eq('id', projectId).single()`
   - `const [currentStep, setCurrentStep] = useState(project?.wizard_step ?? 0)`
3. Create a helper function that wraps step transitions:
```typescript
async function advanceStep(nextStep: number) {
  await supabase.from('projects').update({ wizard_step: nextStep }).eq('id', projectId);
  setCurrentStep(nextStep);
}
```
4. Replace all `setCurrentStep(N)` calls in the step handlers (handleCustomerInfoNext, etc.) with `advanceStep(N)`
5. Also persist when going back (if there's a back button)
