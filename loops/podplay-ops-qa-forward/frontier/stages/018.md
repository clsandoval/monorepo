# Stage 018 — AdjustmentModal Component (F07)

## Spec Reference
- `loops/podplay-ops-qa-forward/spec/qa-fixes-spec.md` § F07

## Instructions
1. Create `apps/podplay/src/components/inventory/AdjustmentModal.tsx`
2. Props:
```typescript
interface AdjustmentModalProps {
  itemId: string;
  itemName: string;
  currentQty: number;
  isOpen: boolean;
  onClose: () => void;
  onSuccess: () => void;  // callback to refresh parent table
}
```
3. Modal contents:
   - Title: "Adjust Inventory: {itemName}"
   - Direction: radio group — "Increase" / "Decrease"
   - Quantity: number input (min=1, required)
   - Reason: text input (required, e.g., "Received shipment", "Correction")
   - Cancel + Submit buttons
4. On submit:
   - Insert into `inventory_movements`: `{ item_id: itemId, movement_type: direction === 'increase' ? 'adjustment_increase' : 'adjustment_decrease', quantity, notes: reason }`
   - Update `inventory` set `quantity_on_hand = quantity_on_hand + qty` (or minus for decrease)
   - Show toast: "Inventory adjusted: +/-{qty} {itemName}"
   - Call `onSuccess()` to refresh
   - Close modal
5. Validate: cannot decrease below 0 (compare quantity against currentQty)
6. Use existing dialog/modal pattern from the codebase (Radix Dialog or similar)
