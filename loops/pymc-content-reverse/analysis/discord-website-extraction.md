### Key SEO issues addressed

**Sitemap issues (Oct–Nov 2025):**
- Blog sitemap previously only updated on redeploy; Inaam made it dynamic
- New posts not appearing in sitemap immediately upon publishing
- Service pages appearing in search results after removal (resolved via Google Search Console removals tool)

- Team detail pages had inverted H-tag structure (H2 for name, H1 for "Biography") — fixed by Inaam (2025-10-29)
- H-tags erroneously used in "Related Articles" section — fixed (Nov 2025)

**Image optimization:**
- Cover images not compressed before upload; Inaam clarified Next.js Image optimization doesn't apply to og:image/meta tags (Dec 2025)
- 3MB cover images flagged by Stephan; manual compression required

**Category filter pages:**
- Initially showed only categories with published blogs (after Inaam's fix, 2025-12-08)
- Stephan: categories in dropdown are HTML links, so Google can crawl them even if not visible in UI

**rel=canonical:**
- Added across key pages
- For pymc-marketing.io docs: rel=canonical should point to `/stable/` version (scikit-learn model)
- Pages with `/index.html` suffix should have canonical pointing to trailing-slash URL

**Schema markup:**
- Schema generator used: https://technicalseo.com/tools/schema-markup-generator/
- Organization schema: sitewide
- Article schema: blog posts
- Course schema: course pages (with price and instructors)
- AggregateRating schema discussed for course pages (Stephan Reiss, 2026-01-27)

**pymc-marketing.io SEO issues:**
- `latest` vs `stable` URL duplication (Stephan, Nov 2025)
- Spanish (`/es/`) 404s — Oriol explained these were URLs that never existed in older versions
- Canonical pointing to stable version recommended
