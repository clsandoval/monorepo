**2. Team pedigree**

Thomas (2022-09-06):

Maxim (2022-02-10):
> "So it's about targeting a broader audience to communicate what we do. They can be as follows:
> - Point estimate: what is the ROI on the project?
> - Bayesian 1: what is the ROI on the project in the worst case?

**4. Custom models, not off-the-shelf**

Niall (2025-12-03):
> "one of the core reasons why people go towards pymc-marketing: because it supports out of sample prediction — I had a call yesterday with a client who was migrating because meridian doesn't support forecasting"

**5. Open source at the core**

Ben Vincent (2023-04-03):
> "PyMC-Marketing is an open source software project that offers a powerful set of tools for data scientists and senior decision makers in the marketing analytics space... why using an open source package like this can be advantageous for your marketing analytics needs"

**6. Speed to insight via agentic AI**

From webinar copy (2025-06-05):
> "Imagine streamlining data exploration, validation, model fitting, and interpretation — so you can spend less time wrangling data and debugging code and more time driving strategy."

Purna (UTC+05:30), 2025-06-05:
> "What if we told you that you could compress weeks of Bayesian MMM work into minutes? Yes, you read that right."

**7. AI agents with scientific rigor**

Halah (2026-02-03):
> "We need to stop testing Agents like Software, and start testing them like Scientists.
>
> We are currently witnessing a 'Reliability Gap' in AI. We have agents that are excellent at coding, but we are judging them with software engineering metrics (syntax, runtime errors, latency).
>
> To bridge this gap, we need a new layer of infrastructure. We need Scientific Guardrails."

**8. Domain expertise in applied Bayesian work**

From the PyMC Skills benchmark (Halah, 2026-02-20):
> "Can domain-specific expertise make AI-generated Bayesian models more reliable?
>
> Pass rates improved from 60% to 93%
> Convergence improved on technically challenging models
> Best practices (like coords/dims and nutpie) were applied far more consistently"

**9. Interpretable models for regulated industries**

Thomas (2022-01-30, paraphrased): biotech requires interpretability; Bayesian methods provide it naturally. Healthcare, pharma, and agriculture all need to explain their predictions, not just make them.

**10. Agentic Data Science — the emerging differentiator (2026)**

Luca (Agentic Data Science blog, 2026-03-06):
> "Systems that automate 'plumbing' — cleaning CSVs or writing SQL (L2) — are becoming common. But in predictive modeling, an agent without an understanding of uncertainty is a liability. In engineering, an L2 error breaks the code. In ADS, the most dangerous errors don't break the code. If an agent automates a model but fails to perform a Posterior Predictive Check, it hasn't just failed — it's still running."
