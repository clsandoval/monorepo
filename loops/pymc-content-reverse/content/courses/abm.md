## Course Description

Interactive, hands-on cohort teaching practical Bayesian modeling using PyMC. Designed for data practitioners who want to move beyond black-box models and build interpretable, uncertainty-aware solutions.

**What makes this course different:** taught by PyMC core contributors and PyMC Labs practitioners who build these models for enterprise clients every day. Sessions move directly from theory to code — every concept is implemented in live notebooks you keep.

---

## Who Is This For

**Target audience:** Software engineers, data analysts, and data scientists who want to move beyond black-box models and build interpretable Bayesian solutions.

**Not required:** Prior Bayesian experience.

**Prerequisites:**
- Basic Python programming experience
- Familiarity with NumPy
- Comfort with Jupyter Notebooks

## FAQs

**Will MMMs be covered?**
No, but you'll learn the foundational tools for Bayesian MMM. Our Bayesian Marketing Analytics course covers MMM directly.

**Can I miss sessions?**
Yes — recordings are available throughout the course, and instructors are available on Discord between sessions.

**What's the refund policy?**
Full refund if cancelled 7+ days before start. 14-day withdrawal right from registration.

**How much time outside sessions?**
Notebooks + Discord available for practice between sessions. Expect 1–3h per week for exercises.

**Is corporate/team training available?**
Yes — contact [email protected] for group pricing. Beginner/intermediate/advanced levels customizable.

**What tools do I need?**
Python, Jupyter Notebooks. We recommend pixi for environment setup (fastest). Google Colab available as fallback.
