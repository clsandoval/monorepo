# Stage 085 — Convergence Gate

**Category**: Convergence Gate
**Priority**: 5

## Task

Final convergence check. ALL of the following must pass for the loop to converge:

1. **Build passes**: `npm run build` exits 0 with no errors
2. **Tests pass**: `npm run test` exits 0 (or no test suite configured)
3. **DB reset clean**: `npx supabase db reset` runs without errors
4. **All screenshots show real content**: Review all screenshots in `loops/podplay-ops-qa2-forward/screenshots/` — none should show error pages, blank screens, or placeholder content
5. **No orphaned references**: Stage 082 findings resolved
6. **No column mismatches**: Stage 083 findings resolved
7. **No stub routes**: Stage 084 findings resolved

If all checks pass, write `loops/podplay-ops-qa2-forward/status/converged.txt` with timestamp and summary, then commit.

If any check fails, document the failure and create additional fix stages as needed. Do NOT write `converged.txt` until all checks pass.

## Setup

```bash
cd apps/podplay && npx supabase status || npx supabase start
```

## Verify

```bash
cd apps/podplay
npm run build && echo "BUILD: PASS" || echo "BUILD: FAIL"
npm run test 2>/dev/null && echo "TEST: PASS" || echo "TEST: SKIP (no suite)"
npx supabase db reset && echo "DB RESET: PASS" || echo "DB RESET: FAIL"

# If all pass:
mkdir -p ../../loops/podplay-ops-qa2-forward/status
echo "Converged at $(date -u +%Y-%m-%dT%H:%M:%SZ)" > ../../loops/podplay-ops-qa2-forward/status/converged.txt
echo "All checks passed: build, test, db reset, screenshots verified, no orphans, no column mismatches, no stub routes." >> ../../loops/podplay-ops-qa2-forward/status/converged.txt
```
