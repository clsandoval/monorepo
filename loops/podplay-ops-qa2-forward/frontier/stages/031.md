**Category**: New Feature

## Task

Add manual "Set On-Order" action to the inventory page.

1. Open the inventory page component(s)
2. Add a "Set On-Order" action per row (button or menu item)
3. On click: show a modal with:
   - SKU name (read-only)
   - Current on-order quantity (read-only)
   - New on-order quantity (input)
   - Reason/notes (text input, optional)
4. On submit: update `inventory.qty_on_order` and `order_status`
5. This is for orders placed outside the app (manual override)
