# Stage 083 — Discovery: DB Query Column Name Audit

**Category**: Discovery
**Priority**: 9

## Task

Audit all Supabase query calls in the frontend to ensure column names match the actual database schema.

1. Grep all `.from('` calls in `apps/podplay/src/` to find every Supabase table access
2. For each table accessed, find the corresponding migration in `apps/podplay/supabase/migrations/` to get the canonical column names
3. Cross-reference `.select(`, `.insert(`, `.update(`, `.eq(`, `.order(` calls against the migration schemas
4. Identify any column name mismatches (e.g. camelCase in code vs snake_case in DB, typos, references to dropped columns)
5. Fix any mismatches found

Common issues to look for:
- `camelCase` column names in queries when DB uses `snake_case`
- References to columns that were renamed or removed in later migrations
- Missing columns in `.select()` that are needed by the UI
