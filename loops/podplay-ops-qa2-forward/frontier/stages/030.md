# Stage 030 — Inventory On-Order: PO Auto-Update

**Category**: New Feature
**Priority**: 4 — BUILD
**Finding**: Q20

## Task

When a PO is created in procurement, auto-update inventory on-order quantities.

1. Find where POs are created (likely in `apps/podplay/src/components/wizard/procurement/PoCreateForm.tsx`)
2. After a PO is successfully created, for each item in the PO:
   - Update `inventory` row: increment `qty_on_order` by the PO quantity
   - Set `order_status` to `ordered`
3. Find where PO receiving happens (likely `PoReceivingPanel.tsx` or similar)
4. When items are received:
   - Decrement `qty_on_order` by received quantity
   - Increment `quantity_on_hand` by received quantity
   - Update `order_status` based on remaining on-order qty (0 = `received`, >0 = `partial`)
