# Stage 021 — Wizard Step Locking: Logic

**Category**: UX Improvement
**Priority**: 3 — IMPROVE
**Finding**: Q11

## Task

Add step completion tracking logic for wizard step locking.

1. Create or update a utility in `apps/podplay/src/lib/` (e.g., `wizard-steps.ts`) that:
   - Defines which steps exist for each wizard (intake, procurement, deployment, financials)
   - Tracks which steps are "complete" (form saved/submitted)
   - Determines which steps are "unlocked" (current + all previous completed steps)
   - Returns step state: `completed`, `current`, `locked`
2. Step completion should be derived from the project's saved data — if a step's required fields are filled, it's complete
3. Export a hook or utility function that components can use
