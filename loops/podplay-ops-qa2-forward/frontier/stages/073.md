# Stage 073 — Mobile Verify: /settings/vendors + /settings/pricing

**Category**: Mobile Verify
**Priority**: 7

## Task

Navigate to `/settings/vendors` and `/settings/pricing` at 375x812 viewport with Playwright. For each route assert:
1. Page renders correctly on mobile
2. No horizontal overflow (document.documentElement.scrollWidth <= window.innerWidth)
3. All interactive elements have touch targets >= 44px
4. CRUD controls and form inputs are usable on mobile
5. Minimum deposit field on pricing page is accessible

## Setup

```bash
cd apps/podplay && npx supabase status || npx supabase start
cd apps/podplay && npm run dev -- --port 5175 &
sleep 5
```
