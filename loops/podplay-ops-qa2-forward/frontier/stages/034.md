# Stage 034 — Wizard Navigation Component

**Category**: New Feature
**Priority**: 4 — BUILD
**Finding**: Q21

## Task

Create a reusable wizard navigation component with step indicators and prev/next buttons.

1. Create `apps/podplay/src/components/wizard/WizardNavigation.tsx`
2. Props:
   - `steps: { id: string; label: string; status: 'completed' | 'current' | 'locked' }[]`
   - `onStepClick: (stepId: string) => void`
   - `onPrevious: () => void`
   - `onNext: () => void`
   - `isFirstStep: boolean`
   - `isLastStep: boolean`
   - `nextLabel?: string` (defaults to "Next", last step shows "Complete")
3. Top section: horizontal step indicator showing all steps with status styling
   - Completed: checkmark, clickable
   - Current: highlighted, active
   - Locked: greyed out, not clickable (integrates with Q11 step locking)
4. Bottom section: Previous / Next buttons
   - "Previous" hidden on first step
   - "Next" validates current form before advancing
