# Stage 072 — Mobile Verify: /settings + /settings/team + /settings/installers

**Category**: Mobile Verify
**Priority**: 7

## Task

Navigate to `/settings`, `/settings/team`, and `/settings/installers` at 375x812 viewport with Playwright. For each route assert:
1. Page renders correctly on mobile
2. No horizontal overflow (document.documentElement.scrollWidth <= window.innerWidth)
3. All interactive elements have touch targets >= 44px
4. CRUD controls are accessible on mobile
5. Navigation between settings sub-pages works

## Setup

```bash
cd apps/podplay && npx supabase status || npx supabase start
cd apps/podplay && npm run dev -- --port 5175 &
sleep 5
```
