# Stage 084 — Discovery: Route Completeness

**Category**: Discovery
**Priority**: 9

## Task

Verify every route in the router tree renders real content (not stubs or placeholders).

1. Read the router configuration (e.g. `apps/podplay/src/App.tsx` or `apps/podplay/src/router.tsx`) to enumerate all defined routes
2. For each route, navigate to it with Playwright at 1280x800
3. Check for stub/placeholder indicators:
   - Text containing "Coming soon", "TODO", "Placeholder", "Not implemented"
   - Empty content areas (main content area has no children or only whitespace)
   - Default React boilerplate text
4. If any route shows stub content, create fix stages or fix inline if trivial
5. Document all routes and their status
