# Stage 079 — Flow QA: Settings Management

**Category**: Flow QA
**Priority**: 8

## Task

End-to-end flow test with Playwright at 1280x800: Test CRUD operations across all settings pages.

1. **Team contacts** (`/settings/team`):
   - Add a new team contact with name, role, phone
   - Assert it appears in the list
   - Edit the contact's role
   - Assert the update is reflected
   - Delete the contact
   - Assert it is removed from the list

2. **Installers** (`/settings/installers`):
   - Add a new installer
   - Assert it appears in the list
   - Delete the installer

3. **Vendors** (`/settings/vendors`):
   - Add a new vendor
   - Assert it appears in the list (verify no crash — vendors page had a prior bug)
   - Delete the vendor

4. **Pricing** (`/settings/pricing`):
   - Update the minimum deposit value
   - Assert the new value persists after page refresh
