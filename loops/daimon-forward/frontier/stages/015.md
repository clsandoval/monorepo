# Stage 015 — Supabase Client + TypeScript Types

## Spec Files
- `database/schema.md`

## Instructions
1. Install `@supabase/supabase-js`
2. Create `src/lib/supabase/client.ts` — browser client using `createBrowserClient`
3. Create `src/lib/supabase/server.ts` — server client using cookies for SSR
4. Run `npx supabase gen types typescript --local > src/lib/supabase/database.types.ts` to generate types from local schema
5. Create `src/lib/supabase/types.ts` re-exporting table row types for convenience (e.g., `Tenant`, `TenantMember`, `DiscordConnection`, etc.)
