# ops-knowledgebase-chat — Design System

## Aesthetic Direction: Control Room Warmth

An industrial-utilitarian ops interface with warm undertones. Think clean dashboards in a well-run kitchen operation. Functional density, sharp typographic hierarchy, and Mama Sita's brand colors appearing only at inflection points — active states, status indicators, key actions. Warm grays (not cold blue-grays) give the tool soul without sacrificing professionalism.

**Memorable detail:** Tool use blocks render like ops terminal logs — monospace, timestamped, with a subtle left-border accent in gold when active. The assistant's responses feel like briefings, not chat bubbles.

## Typography

### Font Stack

| Role | Font | Weight | Fallback |
|------|------|--------|----------|
| **Display / Headers** | Instrument Sans | 600, 700 | system-ui, sans-serif |
| **Body / UI** | Nunito Sans | 400, 500, 600 | system-ui, sans-serif |
| **Code / Tool Output** | IBM Plex Mono | 400, 500 | ui-monospace, monospace |

**Why these fonts:**
- **Instrument Sans** — Sharp geometric display face. Feels authoritative in headers without being aggressive. The slightly condensed proportions give density.
- **Nunito Sans** — Warm, rounded terminals add approachability to an otherwise industrial interface. Excellent x-height for small UI text.
- **IBM Plex Mono** — Industrial heritage matches the utilitarian direction. Superior readability at small sizes vs Fira Code or JetBrains Mono.

### Scale

| Token | Size | Line Height | Letter Spacing | Usage |
|-------|------|-------------|----------------|-------|
| `--text-xs` | 11px | 1.45 | 0.02em | Timestamps, metadata |
| `--text-sm` | 13px | 1.5 | 0.01em | Tool output, secondary labels |
| `--text-base` | 15px | 1.6 | 0 | Body text, chat messages |
| `--text-lg` | 17px | 1.5 | -0.01em | Section headers in messages |
| `--text-xl` | 21px | 1.35 | -0.02em | Page titles |
| `--text-2xl` | 28px | 1.2 | -0.03em | Display (rarely used) |

### Rules

- Headers always use **Instrument Sans 600+**
- Body text always uses **Nunito Sans 400/500**
- Anything the agent produced (tool calls, code, file paths) uses **IBM Plex Mono**
- No text smaller than 11px
- Line lengths in chat messages capped at 72ch for readability

## Spacing

### Base Unit

`4px` base. All spacing is multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-1` | 4px | Tight gaps (icon-to-label) |
| `--space-2` | 8px | Inline padding, small gaps |
| `--space-3` | 12px | Default component padding |
| `--space-4` | 16px | Card padding, section gaps |
| `--space-5` | 20px | Group separation |
| `--space-6` | 24px | Major section padding |
| `--space-8` | 32px | Layout-level gaps |
| `--space-10` | 40px | Page-level padding |
| `--space-12` | 48px | Major layout breaks |

### Layout

- Chat area: `max-width: 768px`, centered
- Input bar: full width, pinned to bottom
- Header: `height: 48px`, fixed
- Message padding: `16px 20px`
- Tool use blocks: `12px 16px` with `2px` left border

---

## Border Radius

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 4px | Buttons, small inputs |
| `--radius-md` | 6px | Cards, tool blocks, code blocks |
| `--radius-lg` | 10px | Message bubbles, modals |
| `--radius-full` | 9999px | Badges, pills, avatars |

**Philosophy:** Minimal rounding. This is an ops tool, not a consumer app. Slightly rounded corners prevent harshness but stop well short of "bubbly."

---

## Shadows & Elevation

Minimal. Depth is communicated through surface color steps, not shadows.

| Token | Value | Usage |
|-------|-------|-------|
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.3)` | Subtle lift (dropdowns) |
| `--shadow-md` | `0 4px 12px rgba(0,0,0,0.4)` | Modals, floating elements |
| `--shadow-input` | `0 0 0 1px var(--border-default)` | Input focus ring base |
| `--shadow-focus` | `0 0 0 2px var(--accent-red)` | Focused interactive elements |

## Component Styles

### Header

```
Background: var(--surface-0)
Height: 48px
Border-bottom: 1px solid var(--border-default)
Title: Instrument Sans 600, var(--text-base), var(--text-secondary)
   └── "ops-kb" in var(--text-muted), monospace — understated branding
Buttons: Ghost style, var(--text-secondary), hover → var(--text-primary)
```

The header is intentionally quiet. It labels the tool and provides escape hatches (New Session, Settings). Nothing more.

### Chat Messages

**User messages:**
```
Background: var(--surface-2)
Border-radius: var(--radius-lg)
Padding: var(--space-3) var(--space-4)
Text: var(--text-primary), Nunito Sans 400
Alignment: right-aligned, max-width 85%
```

**Assistant messages:**
```
Background: transparent (no bubble)
Padding: var(--space-3) 0
Text: var(--text-primary), Nunito Sans 400
Alignment: left-aligned, full width (up to 72ch)
Markdown: Full rendering with styled headings, lists, tables
```

**Design decision:** Assistant messages have NO bubble/background. They flow like document content — a briefing, not a conversation. This creates clear visual asymmetry: user = contained bubble, assistant = open content.

### Tool Use Blocks

```
Background: var(--tool-bg)
Border-left: 2px solid var(--tool-border)
Border-left (active): 2px solid var(--tool-border-active) [gold]
Border-radius: var(--radius-md) (top-right, bottom-right only)
Padding: var(--space-3) var(--space-4)
Font: IBM Plex Mono, var(--text-sm)
```

**Collapsed state:**
```
┌ [▸] Read  entities/people/john-doe.md                    0.2s
```

**Expanded state:**
```
┌ [▾] Read  entities/people/john-doe.md                    0.2s
│
│   ---
│   type: person
│   name: John Doe
│   ...
│
└───
```

- Tool name in **IBM Plex Mono 500**, gold accent when running
- File paths / inputs in muted text
- Duration badge right-aligned, `var(--text-xs)`
- Expand/collapse via chevron, entire header row is clickable
- Multiple consecutive tool blocks stack with `4px` gap (tight grouping)

### Code Blocks (in Markdown)

```
Background: var(--code-bg)
Border: 1px solid var(--border-default)
Border-radius: var(--radius-md)
Padding: var(--space-4)
Font: IBM Plex Mono 400, var(--text-sm)
Line-height: 1.6
```

- Language label top-right in `var(--text-muted)`, `var(--text-xs)`
- Copy button appears on hover, top-right
- Syntax highlighting: muted palette — no neon. Strings in gold-tinted, keywords in red-tinted, comments in `var(--text-muted)`

### Chat Input

```

Border: 1px solid var(--border-default)

Border-radius: var(--radius-md)
```

- Send button: `var(--accent-red)` background, `var(--text-inverse)` text, `var(--radius-sm)`

## Motion

### Philosophy

Minimal, functional motion. No decorative animations. Movement communicates state changes.

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Message appear | Fade in + slide up 8px | 200ms | ease-out |
| Tool block expand | Height reveal | 150ms | ease-out |
| Tool block collapse | Height collapse | 120ms | ease-in |
| Button hover | Background color | 120ms | ease |
| Focus ring | Opacity | 100ms | ease |
| Streaming indicator | Opacity pulse | 1.5s | ease-in-out, infinite |
| Input grow | Height | 100ms | ease-out |

No spring physics, no bounces, no parallax. This is a work tool.

## Iconography

- Use **Lucide React** icons (consistent stroke width, minimal aesthetic)
- Icon size: 16px default, 20px for primary actions
- Stroke width: 1.5px
- Color: inherits from text color of parent

Key icons:
- Send → `ArrowUp` (not paper plane — more utilitarian)
- Upload → `Paperclip`
- New session → `Plus`
- Settings → `Settings`
- Expand → `ChevronRight` / `ChevronDown`
- Copy → `Copy` / `Check` (on success)
- Stop/Interrupt → `Square`
- Connected → `Circle` (filled, 6px, green)

## Anti-Patterns

These are explicitly banned from the implementation:

1. **No gradient backgrounds** — Flat surfaces only
2. **No colored chat bubbles for assistant** — Assistant text flows openly
3. **No avatar circles** — Wastes space, adds nothing in single-user tool
4. **No typing indicators with bouncing dots** — Use the gold streaming dot
5. **No rounded pill buttons** — Square-ish with subtle radius
6. **No emoji in UI chrome** — Use Lucide icons for all UI elements
7. **No blur/glassmorphism** — Solid surfaces, clear hierarchy
8. **No purple or blue accent colors** — Stick to the warm palette
9. **No "AI assistant" branding** — It's a knowledge base tool, not a chatbot persona
10. **No light mode** — Dark only for v1
