# kbase-chat — Design System

## Aesthetic Direction: Clean Professional

A professional, clean knowledge base interface. Functional density, sharp typographic hierarchy, and blue accents at inflection points — active states, status indicators, key actions. Neutral warm grays keep the interface approachable without sacrificing professionalism.

**Memorable detail:** Tool use blocks render like ops terminal logs — monospace, with a subtle left-border accent in blue when active. The assistant's responses feel like briefings, not chat bubbles.

---

## Color System

### Philosophy

The palette is built on warm neutral grays. Blue is the *signal color* — it draws the eye to what matters. Everything else recedes.

## Typography

### Font Stack

| Role | Font | Weight | Fallback |
|------|------|--------|----------|
| **Display / Headers** | Instrument Sans | 600, 700 | system-ui, sans-serif |
| **Body / UI** | Nunito Sans | 400, 500, 600 | system-ui, sans-serif |
| **Code / Tool Output** | IBM Plex Mono | 400, 500 | ui-monospace, monospace |

### Scale

| Token | Size | Line Height | Letter Spacing | Usage |
|-------|------|-------------|----------------|-------|
| `--text-xs` | 11px | 1.45 | 0.02em | Timestamps, metadata |
| `--text-sm` | 13px | 1.5 | 0.01em | Tool output, secondary labels |
| `--text-base` | 15px | 1.6 | 0 | Body text, chat messages |
| `--text-lg` | 17px | 1.5 | -0.01em | Section headers in messages |
| `--text-xl` | 21px | 1.35 | -0.02em | Page titles |
| `--text-2xl` | 28px | 1.2 | -0.03em | Display (rarely used) |

## Anti-Patterns

1. **No gradient backgrounds** — Flat surfaces only
2. **No colored chat bubbles for assistant** — Assistant text flows openly
3. **No avatar circles** — Wastes space
4. **No typing indicators with bouncing dots** — Use the streaming dot
5. **No rounded pill buttons** — Square-ish with subtle radius
6. **No emoji in UI chrome** — Use Lucide icons
7. **No blur/glassmorphism** — Solid surfaces, clear hierarchy
8. **No light mode** — Dark only for v1 (optional future addition)
