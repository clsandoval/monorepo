<objective>
Every claim Phase 18 makes has the form "the two engines now share one date". Nothing can be claimed
about sharing without a measured starting state, and three later plans are verified by re-running the
same measurement and watching a specific number move. This plan takes those measurements once, before
any source file is edited, and records them in `18-BASELINE.md`.

Four quantities are established, each of which a later plan drives to a target or holds fixed:

1. **Second-spine control count** — the number of controls in `frontend/src/` that write
   `EstateTaxWizardState.decedent.dateOfDeath`. Plan `18-03` drives this to 0.
2. **Tax-engine sensitivity** — the exact `deductionRules`, medical deduction and `tax_due` produced
   by one fact set computed at `2017-12-31` and at `2018-01-01`. Plan `18-05` turns this pair into a
   gate assertion, and plan `18-06` confirms the figures did not move.
3. **Succession-engine invariance** — the number of committed corpus inputs whose serialized engine
   output changes when only `decedent.date_of_death` changes. This is expected to be 0 and is
   expected to stay 0; it is the evidence that unifying the field moves no legal outcome.
4. **Missing-date behaviour** — what `computeEstateTax` returns when the date of death is the empty
   string. Plan `18-04` replaces the observed silent result with a refusal.

The plan writes no reusable module. The measurement commands are short enough to live inside this
plan's `<verify>` blocks verbatim, and plan `18-05` re-expresses the two engine measurements as gate
assertions in typechecked source rather than importing a throwaway script.
</objective>

<constraints>

  `scripts/`, any test, `gates.manifest.json`, `gates.manifest.lock`, `gate-skips.lock`,

- If `frontend/src/wasm/pkg/inheritance_engine_bg.wasm` is absent, this plan stops and reports
  BLOCKED with the pasted `ls` output. Rebuilding it is `bash engine/build-wasm.sh`, which is gate
  G2's own command and a separate decision from this measurement.
- `bash scripts/ci-gates.sh` exits 1 at G3 on this branch for a reason this phase does not own. This

- No point of Philippine law is decided. Where a measurement touches RA 11642, the measurement is

</constraints>

<threat_model>
This plan reads committed JSON fixtures, committed TypeScript source and a committed WASM binary, and
writes one Markdown file under `.planning/`. It opens no socket, contacts no database and reads no
credential.

The one real hazard is **a measurement that reports success because it measured nothing**. A glob
matching zero files, or a WASM load that silently produced no result, would print `0 changed` and
every later plan would inherit a false green — and `0 changed` is exactly the number this plan
expects for the succession engine, so a broken harness and a correct result look identical. The
defence is that Task 3 asserts a **positive** computed-file count and a **positive** heir-row count
before the change count is believed, and that Task 2 asserts the two tax figures **differ** from each
other, which a harness returning nothing cannot fake.

A second hazard is scope: the corpus inputs carry invented decedent and heir names. `18-BASELINE.md`
records counts, article-free rule names and centavo integers only; no heir name is copied into a
planning file.
</threat_model>

import fs from 'node:fs';
import path from 'node:path';
import { computeEngineOutput } from '../journey/engine.mjs';
const dirs = ['cases', 'coverage-cases', 'testate-cases', 'fuzz-cases', 'defect-cases'];
const base = path.resolve('..', 'engine', 'examples');
let files = 0, computed = 0, rejected = 0, ra8552 = 0, rows = 0, changed = 0;
const changedFiles: string[] = [];
for (const d of dirs) {
  const p = path.join(base, d);
  if (!fs.existsSync(p)) continue;
  for (const f of fs.readdirSync(p).filter((x) => x.endsWith('.json')).sort()) {
    files++;
    const raw = JSON.parse(fs.readFileSync(path.join(p, f), 'utf8'));
    if (JSON.stringify(raw).includes('Ra8552')) ra8552++;
    let a, b;

    try { b = await computeEngineOutput(alt); } catch { rejected++; continue; }
    if (JSON.stringify(a) !== JSON.stringify(b)) { changed++; changedFiles.push(d + '/' + f); }
  }
}
