<constraints>

1. **No npm dependency is added.** `frontend/package.json` and `frontend/package-lock.json` are not
   edited. The three poppler binaries are invoked through `node:child_process`, and
   `@react-pdf/renderer`, `react` and `pngjs` are already dependencies.

2. **`journey/pdf.mjs` is the only file in the repository that spawns a PDF tool.** Every later
   consumer imports from it. A second `spawn('pdftotext')` anywhere else is a second place for the
   invocation to drift.

3. **A missing binary is a cannot-run condition with its own marker, never a pass and never a
   failure.** Each reader throws an `Error` whose message begins `PDF TOOLCHAIN MISSING: `, and the
   probe maps that to exit `2`. An empty extraction from a present binary is a *different* condition
   and gets its own marker.

4. **The probe writes nothing outside the operating system temporary directory it creates with
   `fs.mkdtemp`, and removes that directory in a `finally`.** It never writes into
   `frontend/journey/`, never into `frontend/src/`, and never into any reference directory.

5. **The exit contract is the project's three-valued one.** `0` everything held, `1` a check failed,
   `2` the check could not run. Exit `2` is printed with the `PDF PROBE CANNOT RUN: ` prefix on
   stderr.

6. **`GATE-SKIPS total=<n> skipped=<n>` is printed on stdout on both the pass and the fail path.**
   `scripts/check-gate-skips.mjs` (G8) reads that line out of the gate log and treats a missing line
   as a failure rather than as zero skips.

7. **No application source file, no test, no rubric, no step record and no seed file is edited.**
   This plan adds two harness files and nothing else.

8. **Commit explicit paths only** with `bash scripts/safe-commit.sh -m "<message>" <path> ...`.
   `git add -A`, `git add .` and `git commit -a` are prohibited.

9. **No point of Philippine law arises in this plan.** Every function reads bytes out of a document.

<interfaces>

### `frontend/journey/pdf.mjs`

```
export function extractPdfText(pdfBuffer) -> string
export function pdfPageInfo(pdfBuffer) -> { pages: number, widthPt: number, heightPt: number }
export function rasterizePdfPages(pdfBuffer, dpi) -> Buffer[]
```

All three are synchronous, take the PDF as a `Buffer`, write the buffer to a freshly created
`fs.mkdtempSync` directory, invoke the tool with `child_process.spawnSync`, read the result back and
remove the directory in a `finally`.

| Function | Command | Returned |
|---|---|---|
| `extractPdfText` | `pdftotext <tmp>/in.pdf -` | `stdout` decoded as UTF-8 |
| `pdfPageInfo` | `pdfinfo <tmp>/in.pdf` | `pages` from the `Pages:` line; `widthPt` and `heightPt` parsed from the `Page size:` line, which reads `595.28 x 841.89 pts (A4)` |
| `rasterizePdfPages` | `pdftoppm -png -r <dpi> <tmp>/in.pdf <tmp>/page` | every produced `page*.png`, read as `Buffer`, ordered by the integer suffix in the filename |

`pdftoppm` zero-pads the suffix once a document reaches ten pages, so the ordering is by the parsed
integer, never by string sort.

Three thrown conditions, each with its own literal prefix:

| Prefix | Thrown when |
|---|---|
| `PDF TOOLCHAIN MISSING: ` | `spawnSync` reports `ENOENT`, or the process exits with a status indicating the binary was not found |
| `PDF TOOL FAILED: ` | the binary ran and exited non-zero; the message carries the tool name and its `stderr` |
| `PDF UNREADABLE: ` | the binary exited zero but produced nothing usable — empty text, no `Page size:` line, or zero PNG files |

A caller that catches nothing gets a thrown `Error`; no reader ever returns a default value on
failure.

### `frontend/journey/pdf-probe.mjs`

Run from `frontend/`. No arguments. It builds one two-page PDF at run time with
`@react-pdf/renderer` and `React.createElement` — no JSX, since this is a `.mjs` file — containing two
`<Page size="A4">` elements. Page one carries these four literal strings:

- `Estate of Probe Decedent`
- `Distribution of Shares`
- `PHP 1,234,567.89`
- `Art. 996: Probe citation`

Page two carries the single literal string `Probe page two`.

Seven checks, all evaluated, never short-circuiting:

| Check | Passes when |
|---|---|
| `PROBE PDF BYTES` | the generated buffer starts with the bytes `%PDF-` and is longer than 1000 bytes |
| `PROBE TEXT` | `extractPdfText` output contains all four page-one strings and the page-two string |
| `PROBE TEXT CONTIGUOUS` | the extracted text contains `PHP 1,234,567.89` as one uninterrupted substring, which is the property `13-RESEARCH.md` §2.5 measured and §2.4 showed the peso sign destroying |
| `PROBE NO CORRUPT GLYPH` | the extracted text contains neither `±` nor `₱` |
| `PROBE PAGE INFO` | `pdfPageInfo` returns `pages` `2`, `widthPt` rounded to a whole number `595`, `heightPt` rounded `842` |
| `PROBE RASTER COUNT` | `rasterizePdfPages(buf, 100)` returns exactly 2 buffers, each starting with the 8-byte PNG signature |
| `PROBE RASTER DETERMINISTIC` | rasterising the same buffer a second time yields images whose `sha256` digests equal the first run's, page for page |

Output:

- one line per failing check: `<CHECK NAME> — <what was expected and what was observed>`
- always, on stdout: `GATE-SKIPS total=7 skipped=0`
- pass path: `PDF PROBE PASS checks=7 pages=2` and exit `0`
- fail path: `PDF PROBE FAIL checks=7 failed=<k>` and exit `1`
- cannot-run path: `PDF PROBE CANNOT RUN: <reason>` on stderr and exit `2`
