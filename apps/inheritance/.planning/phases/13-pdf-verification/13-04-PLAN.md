<constraints>

1. **The script never reads `frontend/src/styles/print.css`, and never reads any `.css` file.** That
   is the entire point of PDF-05. `grep -c "print.css\|\.css" frontend/journey/print-layout.mjs` must
   print `0`, and this is an acceptance criterion.

2. **Every claim is read from rendered output**: `getComputedStyle` inside the page under
   `page.emulateMedia({ media: 'print' })`, or the bytes of the document `page.pdf()` produced.

3. **`page.pdf` is called with `preferCSSPageSize: true` and no `margin` option**, so the page size
   and the margins come from the stylesheet's `@page` rule rather than from an argument the check
   supplied itself. Supplying a margin would make the check agree with its own input.

4. **The two margin thresholds are fixed integers: 90 pixels from the top and 70 pixels from the left,
   at a raster resolution of 100 dots per inch.** `13-RESEARCH.md` section 8 records the basis — 25 mm
   is 98.4 px and 20 mm is 78.7 px at that resolution, and both thresholds sit a few pixels inside
   those to absorb glyph bearing while remaining far above the near-zero offset a page ignoring
   `@page` would produce. No other number is introduced and neither threshold is adjusted to make a
   run pass.

5. **No application source file, no stylesheet, no test, no rubric and no step record is edited.**

6. **The exit contract is the project's three-valued one.** A stopped Supabase stack, a failed build,
   a missing browser or a missing PDF tool is exit `2` with the `PRINT LAYOUT CANNOT RUN: ` prefix.

7. **`GATE-SKIPS total=<n> skipped=<n>` is printed on stdout on both the pass and the fail path.**

8. **Commit explicit paths only** with `bash scripts/safe-commit.sh -m "<message>" <path> ...`.
   `git add -A`, `git add .` and `git commit -a` are prohibited.

9. **No point of Philippine law arises in this plan.** Every assertion is about a typeface, a
   visibility, a paper size or a pixel offset.

<interfaces>

### `frontend/journey/print-layout.mjs`

Run from `frontend/`. No arguments.

Setup, each failure being exit `2` with the `PRINT LAYOUT CANNOT RUN: ` prefix:

1. `readStackEnv()` from `./session.mjs`; a null return or a missing `API_URL` cannot run.
2. `readFixtures()` from `./seed.mjs` supplies `orgs.alpha.case_id`; `adminClient(env)` applies
   `RESETS['case-alpha-computed']` so the results view has a distribution to lay out.
3. `buildApp()` and `startPreview()` from `./serve.mjs`; `launchBrowser()` and `newJourneyPage()` from
   `./browser.mjs`.
4. `getSession(env, 'alpha')` and `seedAuthSession(page, origin, session)` from `./seed.mjs`.

Sequence:

1. `page.goto(<origin>/cases/<caseId>)`, wait for `[data-testid="results-view"]`, settle 4000 ms.
2. Read the screen-media baseline: the computed `display` of every `.print-header` element.
3. `await page.emulateMedia({ media: 'print' })`.
4. Read the print-media values with a single `page.evaluate` returning a plain object:
   - `bodyFontFamily`: `getComputedStyle(document.body).fontFamily`
   - `bodyFontSize`: `getComputedStyle(document.body).fontSize`
   - `hiddenCounts`: for each of the selectors `nav`, `[data-sidebar]`, `.sidebar`, `.no-print`, the
     total number of matching elements and how many of them have computed `display` `none`
   - `printHeaderShown`: the number of `.print-header` elements and how many have computed `display`
     `block`
5. `const printed = await page.pdf({ preferCSSPageSize: true })`.
6. `pdfPageInfo(printed)` and `rasterizePdfPages(printed, 100)` from `./pdf.mjs`.
7. Scan page one's PNG with `PNG.sync.read` from `pngjs` for the first row and the first column
   containing a pixel whose red, green and blue channels are each below 250 at an alpha above 0. Those
   are `topInkPx` and `leftInkPx`.

Seven checks, all evaluated, never short-circuiting:

| Marker | Fails when |
|---|---|
| `PRINT FONT FAMILY` | `bodyFontFamily` does not contain `Times New Roman` |
| `PRINT FONT SIZE` | `bodyFontSize` is not `16px` — 12 point at the CSS reference resolution of 96 dots per inch |
| `PRINT CHROME VISIBLE` | for any of the four selectors, at least one element matched and not all matched elements computed `display` `none`; the selector, the total and the hidden count are all named |
| `PRINT ONLY HIDDEN` | at least one `.print-header` element exists and not all of them computed `display` `block`, or none of them was `display` `none` on screen before the media switch |
| `PRINT PAGE SIZE` | the printed document's `widthPt` rounded is not `595`, or its `heightPt` rounded is not `842` |
| `PRINT TOP MARGIN` | `topInkPx` is below `90` |
| `PRINT LEFT MARGIN` | `leftInkPx` is below `70` |

`PRINT CHROME VISIBLE` deliberately passes when a selector matches zero elements: the results route
may legitimately render no `.sidebar`, and asserting a count would be asserting the page's structure
rather than the stylesheet's effect. `PRINT ONLY HIDDEN` compares the screen reading against the print
reading, so a `.print-header` that was already visible on screen fails — otherwise a stylesheet that
did nothing at all would pass.

Output:

- one line per failing check naming what was expected and what was observed
- always, on stdout: `GATE-SKIPS total=7 skipped=0`
- pass path: `PRINT LAYOUT PASS checks=7 topInk=<n> leftInk=<n>` and exit `0`
- fail path: `PRINT LAYOUT FAIL checks=7 failed=<k>` and exit `1`
