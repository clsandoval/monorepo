### `GATES.md` section 15

A new `## 15. The PDF gates` section covering, for each of the four: what it proves, what it needs to
run, the exit contract, and how to read a failure. It also records:

- the observed toolchain versions, `poppler-utils 22.02.0` and `fonts-urw-base35 20200910-1`, and that
  a different version of either would rasterise differently
- that PDF page references live under `frontend/journey/pdf-references/` rather than
  `frontend/journey/references/`, and why: `scripts/check-journey-registry.mjs` requires every image
  in the latter to belong to a declared browser step
- that `journey/pdf-approve.mjs` is the only writer into the reference directory and that no gate
  invokes it
- that the rasterisation parameters, `pdftoppm -png` at 100 dots per inch, are part of the reference
  contract and changing either invalidates every approved image

### `frontend/journey/JOURNEY.md`, section `## The PDF journey`

Records what is covered and, equally, what is not:

- covered: section presence, exact money in both directions, per-heir citation and narrative
  evidence, per-page perceptual diff, and print layout from rendered output
- not covered, with the reason: the firm header section, because `ActionsBar.tsx:49` calls
  `downloadPDF(input, output, null)` and no PDF a user can obtain carries one
- not covered, with the reason: the literal `**` markdown markers the engine writes into
  `narratives[].text`, which reach the page verbatim. `13-RESEARCH.md` section 3 records this
  measurement; removing them is a presentation change with no requirement behind it in PDF-01 through
  PDF-05, and it is written down here so it is not mistaken for something nobody noticed

### The workflow change

One step is inserted after `Install Node` and before `npm ci`:

```yaml
      # Gates G22 through G25 read the generated PDF with poppler: pdftotext for
      # its text, pdfinfo for its page size, pdftoppm for its page images.
      # fonts-urw-base35 supplies the substitution fonts poppler uses, because the
      # PDF's base-14 fonts are not embedded — so this package is part of the
      # rasterisation contract G24's reference images were approved against, not
      # an incidental dependency.
      - name: Install PDF toolchain
        run: sudo apt-get update && sudo apt-get install -y poppler-utils fonts-urw-base35
```
