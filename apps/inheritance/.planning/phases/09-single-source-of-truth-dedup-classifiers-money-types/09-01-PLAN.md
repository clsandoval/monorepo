<objective>
Give the engine a classification entry point the frontend can reach, so that exactly one
implementation of scenario classification can survive Phase 9.

Today `engine/src/wasm.rs` exports one function, `compute_json`, which runs all ten steps including
money. There is no way for the frontend to ask "which scenario is this?" without asking for a full
distribution. That absence is the reason `ReviewStep.tsx` grew its own classifier, and EXT-01 cannot
be satisfied by deletion alone.

This plan adds `classify_scenario` to `engine/src/pipeline.rs`, wraps it as `classify_json` in
`engine/src/wasm.rs`, and proves the new entry point agrees with `run_pipeline` on all 173 committed
inputs. `run_pipeline`'s body is deliberately left alone.

Output: two new public functions, one new test binary, and a rebuilt WASM package.
</objective>
