<objective>
Register a blocking gate that proves, against the document the product's own Export PDF button
produced in the same run, that the letterhead rendered, that the attribution block carries five
labelled values, that every engine warning was printed with its severity and the heir it names, that
no markdown asterisk survived, and that no citation line names its article twice.

Purpose: plans 23-03 through 23-06 change five components and one library module. Unit tests prove
each in isolation; none of them proves that the file a lawyer downloads carries the result. The PDF
gate family already exists for exactly this reason — `journey/pdf-capture.mjs` obtains bytes by
clicking the real button in a real browser, and `journey/pdf-structure.mjs:13-15` currently records
the firm-header exclusion as a deliberate gap that INST-01 closes. This gate is what turns that gap
into an assertion, and what makes the image re-approval in plan 23-08 a recording of an already-proven
change rather than a visual judgement.

Output: two committed fixtures, one optional parameter on the shared capture helper,
`journey/instrument-parity.mjs`, four observed red injections, and registration at order 36.
</objective>

Main flow.

1. `readStackEnv()`; when it is null or has no `API_URL`, `cannotRun('local Supabase stack is not running')`.

4. Open a `try` whose `finally` restores both rows: update `cases` with the stashed `input_json`,

5. Inside the `try`, call `captureExportedPdf({ prepare })` where `prepare` is an async function of
   `admin` that updates the Alpha `cases` row's `input_json` with the warning fixture and updates
   the Alpha `user_profiles` row with the seven profile fixture values. Wrap the call so a
   `JourneyCannotRun` becomes `cannotRun(err.reason)` and a message beginning
   `PDF_MARKERS.TOOLCHAIN_MISSING` becomes `cannotRun(err.message)`.
6. `extractPdfText(captured.pdfBuffer)`; a throw is `cannotRun`. Keep the raw text with its line
   breaks in `rawText`, and build `const text = rawText.replace(/\s+/g, ' ')` for containment tests,
   exactly as `journey/pdf-structure.mjs` does.

Assertions. Accumulate every failure into a `failures` array; never exit at the first one.

**1. LETTERHEAD MISSING.** For `firm_name` and `firm_address` from the profile fixture, when `text`
does not contain the value, push
`` `LETTERHEAD MISSING — the exported document does not contain ${JSON.stringify(value)}, which the firm profile this run configured holds in ${key}` ``.

**2. ATTRIBUTION LINE MISSING.** For each of the five label pairs, the expected substring is the
label, one space, and the fixture's value. When `text` does not contain it, push
`` `ATTRIBUTION LINE MISSING — the exported document does not contain ${JSON.stringify(expected)}` ``.
Count the pairs checked in `attributionChecked`.

**3. WARNING NOT PRINTED.** `captured.expected.warnings` is the engine's own output for this run.
For each warning: when `text` does not contain its `description`, push `WARNING NOT PRINTED` naming
the category and the missing description. Compute the expected severity with a severity map
transcribed into this file — `preterition` and `max_restarts` are `error`; `inofficiousness`,
`disinheritance` and `vacancy_unresolved` are `warning`; `unknown_donee` is `info`; anything else is
`info` — and when `text` does not contain the open bracket, that severity and the close bracket,
push `WARNING SEVERITY NOT PRINTED`. When `related_heir_id` is non-null, resolve the heir name from
`captured.expected.per_heir_shares` and, when `text` does not contain `Related heir:` followed by a
space and that name, push `WARNING HEIR NOT PRINTED`. Additionally, when `text` does not contain
`Manual Review Required`, push `WARNING SECTION MISSING`.

**4. MARKDOWN ASTERISK IN PDF.** When `rawText` contains two consecutive asterisk characters, push
`` `MARKDOWN ASTERISK IN PDF — the extracted text contains a markdown emphasis marker at index ${i}: ${JSON.stringify(context)}` ``
where `context` is forty characters of surrounding text. Search for the marker with `indexOf` on a
two-character string built from `String.fromCharCode(42)` twice, so this file contains no literal
asterisk pair of its own to confuse a later grep.

**5. CITATION ARTICLE REPEATED.** Split `rawText` on newlines. A citation line is one whose trimmed
form matches a leading token of the shape three letters, a period, optional whitespace, one or more
digits, an optional paragraph-sign suffix, optional whitespace, a colon and a space. For each such
line, take the digits from the leading token and count how many times a token naming that same
article number appears in the whole line; when the count is greater than one, push
`` `CITATION ARTICLE REPEATED — ${JSON.stringify(line.trim())} names its article ${count} times` ``.
Count the citation lines found in `citationLines`.

**6. INSTRUMENT CORPUS EMPTY.** When `captured.expected.warnings.length` is 0, or
`attributionChecked` is 0, or `citationLines` is 0, push
`` `INSTRUMENT CORPUS EMPTY — warnings=${n} attributionLines=${m} citationLines=${k}; this run asserted nothing and a gate that examines an empty corpus is not a gate` ``.

Reporting. Print every failure to stderr. Print
`GATE-SKIPS total=${TOTAL_CHECKS} skipped=0` on BOTH the pass and the fail path, because
`scripts/check-gate-skips.mjs` reads that line regardless of outcome. On failure print
`INSTRUMENT PARITY FAIL checks=${TOTAL_CHECKS} failed=${failures.length}` and exit 1. On success
print
`INSTRUMENT PARITY PASS warnings=${w} attributionLines=${a} citationLines=${c} letterhead=1`
and exit 0.

Wrap `main()` in a `.catch` that prints `INSTRUMENT PARITY FAIL checks=? failed=? : ` with the
stack, prints the `GATE-SKIPS` line and exits 1, matching `journey/pdf-structure.mjs`.

Write no flag parsing of any kind. This file reads `process.argv` nowhere.
