<threat_model>

code path is touched.

is closed: registering `G37` at an order before the halt would move the halt earlier and lose `G18`
through `G35` from every run, so the order is fixed at 34 by the constraint; changing `G8`'s or `G9`'s
command while editing their order would break the freeze record, so task 2 diffs every non-order field
and asserts zero changes; and adding a file to `G14`'s `DISPLAY_LAYERS` that legitimately contains an
article literal would turn `G14` red, so task 3 runs `G14` before and after.

Severity: medium. A quiet coverage reduction is invisible in every green run that follows it.
</threat_model>
