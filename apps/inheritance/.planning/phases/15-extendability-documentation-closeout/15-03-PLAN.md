EXT-07 asks that planning docs and specs contain no stale claim contradicted by the code, and ROADMAP

   file in one wave is a merge conflict. `depends_on: [15-01]` serialises them. The `CLAUDE.md`
   correction is deliberately this plan's **last** task, and its first action is to re-read the file
   from disk so `15-01`'s invariants section is picked up rather than overwritten.

The check is designed so it cannot rot into a list of strings someone once believed. Every claim is a
**pair**: a literal string that must be absent from the documents, and a **probe measured from the
tree at run time** that establishes why. If a future change makes the original claim true again — if
`node_modules` is deleted, say — the probe flips and the check stops demanding the correction. No
expected value is hardcoded anywhere.
</objective>
