that needs a computed case without a browser (`share-populated`) gets it from a reset that runs the
real engine at run time.

### `frontend/journey/engine.mjs`

One export. It resolves paths relative to its own module URL so the process working directory does
not matter, exactly as `journey/seed.mjs:23` already does.

```
export async function computeEngineOutput(input): Promise<object>
```

- Loads `../src/wasm/pkg/inheritance_engine.js` with a dynamic `import()`.
- Calls its `initSync` with the bytes of `../src/wasm/pkg/inheritance_engine_bg.wasm`, read with
  `node:fs.readFileSync`, matching what `src/wasm/__tests__/wasm-real.test.ts` already does.
- Initialises at most once per process, guarded by a module-level boolean in the same shape
  `src/wasm/bridge.ts` uses.
- Calls `compute_json(JSON.stringify(input))` and returns `JSON.parse(...)` of the result.
- On a thrown value, rethrows a new `Error` whose message begins `ENGINE REJECTED: ` followed by the
  thrown value's string form. The caller decides what to do; this module never exits the process.
- If `inheritance_engine_bg.wasm` does not exist, throws an `Error` whose message begins
  `ENGINE MISSING: ` and names the path plus the command `bash engine/build-wasm.sh`.

### The two new resets in `frontend/journey/resets.mjs`

```
'case-alpha-no-output': async (admin) => { … }
```
Sets `output_json` to `null` on the single row `readFixtures().orgs.alpha.case_id`, using
`admin.from('cases').update({ output_json: null }).eq('id', <that id>)`. Throws on a returned error
rather than swallowing it, so a failed reset is a `STEP ERROR` and not a mystery rubric failure.

```
'case-alpha-computed': async (admin) => { … }
```
Selects `input_json` for that same row, calls `computeEngineOutput(input_json)` from
`./engine.mjs`, and writes the result to `output_json` on that row. Throws on any returned error and
on a null `input_json`.

Both are added to the existing `Object.freeze({ … })` literal; the three existing entries are not
touched, and the exported `RESET_NAMES` derivation at the bottom of the file already picks new keys
up automatically.
