Three Design Approaches

Minimal, monochrome, Linear/Vercel-inspired — same data, different structures. Click to select.

A

Focused Flow

Navigation: Minimal top bar (logo + nav links + avatar). No sidebar at all.

Wizard: 4-5 consolidated sections on a single centered column (max-w-2xl), each section is a collapsible card. Fill top-to-bottom, compute at the end.

Results: Big hero number at top ("₱42,350 total tax due"), regime recommendation badge, then collapsible detail sections below.

Feel: Like a Typeform meets Linear — one focused task at a time, lots of whitespace, almost no chrome.

B

Split Workspace

Navigation: Ultra-thin left rail (icons only, ~48px) + top breadcrumb bar.

Wizard: Left column shows section outline (4-5 groups), right column shows the active section's fields. Click a section to jump.

Results: Same hero number pattern, but results live in a two-column layout — summary left, detail panels right.

Feel: Like Vercel's dashboard — structured but airy, icon-driven navigation, content-forward.

C

Document Style

Navigation: Minimal header (logo left, nav right). Pages feel like standalone documents.

Wizard: Single long-scroll form styled like a document — section headers break up the flow, sticky progress indicator on the side shows where you are.

Results: Reads like a report — hero number, then flowing sections with clear typographic hierarchy. No cards or boxes, just type and space.

Feel: Like Notion or a well-designed tax document — editorial, typographic, content is the interface.

Shared across all approaches

  • Monochrome palette — near-black backgrounds or pure white, minimal accent color
  • System font stack or Inter/Geist — no decorative serif fonts
  • Keep Tailwind + shadcn (restyle, don't replace)
  • 17 wizard steps → 4-5 consolidated sections
  • Results: bold headline number + progressive disclosure
  • All existing functionality preserved (auth, sharing, PDF, clients, deadlines)
